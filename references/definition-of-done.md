# Definition of Done

Изменение готово только когда применимые пункты подтверждены доказательствами.

## Требования

- Критерии приёмки выполнены.
- Scope не расширен молча.
- Предположения и остаточные риски названы.

## Код

- Реализация минимальна и соответствует существующим границам.
- Публичные API типизированы и документированы.
- Нет временной диагностики, мёртвого кода и секретов.

## Проверки

- Новый тест сначала обнаруживал отсутствие поведения или дефект.
- Unit/integration тесты выбраны на подходящем уровне.
- Ruff, mypy и релевантные tests прошли.
- Coverage не ниже порога и не скрывает пропущенный важный сценарий.

## Эксплуатация

- Конфигурация и `.env.example` актуальны.
- Логи структурированы и не раскрывают чувствительные данные.
- Для Docker/CI выполнены соответствующие проверки.
- Для migration/release определены rollback и health signal.
- Для production-кандидата заполнен контракт передачи и пройден `make production-check`.

## Документация

- README/docs/ADR обновлены в каноническом месте.
- Команды и примеры проверены.
- В отчёте перечислены только реально выполненные проверки.
