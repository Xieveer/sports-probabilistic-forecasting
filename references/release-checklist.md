# Checklist релиза

## До решения

- Состав и версия артефакта однозначны.
- CI, tests, types, lint, docs и применимые security scans зелёные.
- Review findings закрыты или риск явно принят владельцем.
- Config и secrets подготовлены отдельно для целевого окружения.
- `docs/operations/production-handoff.md` имеет статус `candidate` и заполнен без секретов.
- `make production-check` завершён успешно.

## Передача в эксплуатацию

- Указаны команда запуска, healthcheck, smoke-проверка и значимые зависимости.
- Описаны постоянные данные, миграции, резервное копирование и совместимость с откатом.
- Определены структурированные логи, метрики, маскирование данных и пороги оповещений.
- DevOps Operations Agent получил immutable artifact и проверяемые критерии rollout/rollback.
- Production-развёртывание не считается разрешённым без отдельного одобрения владельца.

## Rollout

- Определён способ постепенного включения или ограничена blast radius.
- Health signal отражает пользовательский результат, а не только живой процесс.
- Указаны время наблюдения и критерий остановки.
- Владелец rollout доступен.

## Rollback

- Известна предыдущая исправная версия.
- Данные совместимы с откатом либо есть forward-fix.
- Команда/процедура отката проверена.
- Указан допустимый срок восстановления.

## После

- Проверены логи, ошибки, latency и ключевой бизнес-сигнал.
- Неиспользуемый feature flag имеет срок удаления.
- Инциденты и отклонения зафиксированы.
