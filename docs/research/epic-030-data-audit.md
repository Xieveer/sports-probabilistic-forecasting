## Что проверено

Локальные файлы основного checkout прочитаны без изменения. В отдельную
временную SQLite БД `/tmp/epic-030-historical-audit.sqlite3` импортированы только
`_historical_sports_icehockey_nhl_odds*.json` через существующий
`import_historical_cache`; два `current` JSON исключены.

| Вход | Результат |
| --- | ---: |
| Historical NHL JSON | 1790 файлов, 1609 уникальных содержимых |
| Pinnacle `h2h` | 10805 уникальных observations, 4144 source events |
| События со снимком провайдера к kickoff − 15 минут | 4144 |
| Известное время локального получения в receipts | 0 из 1609 |
| NHL `raw/nhl/matches.parquet` | 22215 строк; 5378 с 2023 года |
| NHL `processed/nhl/train_wide.parquet` | 20591 строк; 5013 с 2023 года |
| `predictions_prod.parquet` для `winner_withOT` | 1624 строки; 365 с 2023 года |

Пробная строгая сверка по UTC kickoff и обеим командам через уже проверенный
`conf/bookmaker/team_name_registry/nhl.yaml` дала **3294** source events с
единственным точным NHL матчем; все 3294 есть в `train_wide.parquet`. Для
остальных 850 точного совпадения нет. Это оценка потенциального объёма, а не
подтверждённый registry mapping: по каждой связи ещё нужны проверки
неоднозначности и provenance. Среди 3294 точных совпадений нет строк из
текущего `predictions_prod.parquet`, поэтому этот файл пока не является
готовым сравнением с действующей моделью на выбранном срезе.

Предварительная проверка предложенного test окна `[2025-10-01,
2026-05-01)` UTC без чтения исходов: 1345 Pinnacle source events, из них 773
имеют точное соответствие с `train_wide` и snapshot провайдера к kickoff − 15
минут. Если дополнительно требовать возраст цены на момент `T` не более 45 минут,
остаётся лишь 138 потенциальных событий; при лимите 12 часов — 550.
Эти числа получены до подтверждения registry и проверки признаков. Порог
давности и минимум test-событий нельзя выбирать по итоговой доходности;
решение Research Scientist фиксирует до эксперимента и сопровождает
анализом чувствительности к давности цены.

Для пересмотренного test окна `[2024-10-01, 2026-05-01)` UTC до чтения исходов
насчитано 2744 Pinnacle source events, 1967 предварительных точных связей с
NHL `train_wide` и 1777 таких связей со снимком провайдера к `T = kickoff − 15
минут` возрастом не более 24 часов. Это верхняя оценка пригодного набора до
закрепления registry и аудита признаков.

Котировки относятся к матчам с 2023-10-10 по 2026-04-27. Число 4144
показывает только временную доступность **снимка провайдера** за 15 минут до
kickoff; это ещё не покрытие пригодного совместного набора с исходами и
признаками. Старый cache не доказывает, что локальная система получила цену
к историческому моменту решения.

Проверенный registry snapshot из [TASK-027-2](../changes/done/TASK-027-2-historical-odds-coverage.md)
содержит два вручную подтверждённых матча; один из них без линии. Поэтому
полный финансовый эксперимент на текущем pinned universe невозможен. Нужна
проверяемая связь NHL матча с source event ID, командами и UTC kickoff для
достаточного периода, новый pinned snapshot и отчёт причин исключения.

## Воспроизведение аудита

Подсчёт observations сделан через `import_historical_cache` из текущего кода
на 1790 отсортированных historical JSON; после импорта SQLite запросы считали
`COUNT(DISTINCT source_event_id)` и сравнивали `observed_at` с
`commence_time − 15 минут`. Числа parquet получены из локальных файлов через
`pyarrow`/`pandas` с UTC-приведением дат. В Git не добавлялись исходные JSON,
parquet или SQLite.
