## Результат

Бот запоминает сообщения одного диалога записи и после подтверждённого API
сохранения удаляет вопросы, ответы владельца и финальное сообщение. Карточка
прогноза остаётся. При отказе API состояние и сообщения остаются для повтора.
Удаление сообщений не изменяет уже записанную ставку; ошибки Telegram пишутся
в лог. Подсказка `/bet_correct` показывает копируемые примеры и, если указан
ID ставки, допустимые исходы её рынка.
