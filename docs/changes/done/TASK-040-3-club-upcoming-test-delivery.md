# TASK-040-3 — Локальная выдача 1X2 на реальном upcoming

> **Статус:** реализация, локальный E2E и независимое review завершены
> **Задача:** [TASK-040-3](../../backlog/tasks/TASK-040-3-club-upcoming-test-delivery.md)
> **Требование:** [REQ-040](../../product/requirements/REQ-040-club-football-platform-e2e.md)

## Изменено

- Адаптер Smart Tables получает реальные будущие `match-center` события всех
  девяти соревнований. Проверяются ID ответа, соревнование, время, статус,
  отсутствие счёта, разные идентификаторы и названия команд. ID этого API
  получают префикс `mc:` во избежание коллизий с историческим `/matches`.
- Отдельный локальный сценарий строит raw/interim/processed и inference-снимки
  со временем и SHA-256 источника, материализует две shadow-модели в
  `data/local_test/predictions.sqlite`, читает их через API и обработчик бота.
- Ingest сохраняет будущие UCL/UEL без счёта, но продолжает отклонять
  завершённые кубковые матчи с непроверенным счётом основного времени.
- Некорректные long-вероятности отправляются в карантин по отдельным матчам;
  если отклонены все матчи, локальная витрина соответствующей стратегии
  опустошается, не затрагивая другие namespace.

## Фактическая проверка

- Red: новый контракт ID и команд сначала завершился двумя `TypeError`;
  после исправления `tests/test_club_upcoming.py` прошёл.
- Первый полный запуск на реальном источнике получил 89 upcoming во всех девяти
  соревнованиях, 178 long и 89 wide inference-строк, по 89 прогнозов каждой
  модели. Отрицательных long-остатков не было. Повторный запуск сохранил ровно
  178 активных записей без дублей. API выдал 168 прогнозов в окне 168 часов;
  `/club_test` показал П1/Х/П2 для обеих стратегий.
- Тестовое сообщение с явной пометкой один раз доставлено единственному
  разрешённому получателю из локального `.env`: Telegram HTTP 200,
  `ok=true`, `message_id=172`. Секреты и chat ID не сохранялись.
- Независимый Reviewer подтвердил устранение замечания P2 по identity источника:
  5 целевых тестов прошли, оставшихся P0/P1/P2 в изменённом срезе нет.

## Не изменено и остаточные риски

Production DB, расписание, модельный pointer и работающий бот не переключались.
Снимок upcoming живёт не более часа. Два артефакта обучены только для проверки
работоспособности пути; исторические odds не имеют подтверждённого времени
получения, поэтому финансовое и production-решение по ним не принималось.
