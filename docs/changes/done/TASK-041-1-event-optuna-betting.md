## Изменено

Optuna получает ID событий для TSCV, выбирает ограниченную последнюю часть
train-истории только для поиска и требует заданное число успешно завершённых
trial. Каталог SQLite study настраивается, поэтому исследование не делит
хранилище с тестовыми fixtures. Финальная модель обучается на всей истории
до holdout.

Общий оценщик 1X2 принимает long и wide вероятности, выбирает максимум одну
ставку на матч при `edge > 0.05` и сохраняет полный trace и финансовые метрики.
Для long явно измеряется доля матчей с невозможным остатком ничьей; эти матчи
не получают ставку, но входят в знаменатель coverage.

При интеграционном review добавлена защита от старых штрафных Optuna-trial,
ошибочно сохранённых как `COMPLETE`: при обнаружении таких записей валидные
trials переносятся в отдельное study, чтобы sampler и выбор результата не
использовали штрафы; исходное study не изменяется. Отсутствующие коэффициенты
исключают матч из ставок, а полностью отклонённые long-распределения
сохраняют число отказов и coverage без недоступных вероятностных метрик.

## Проверка

Адресные тесты проверяют группировку сторон одного матча, повтор после
ошибочного trial, изоляцию study, выбор максимального edge, ничейный исход,
невалидный остаток и знаменатель coverage. Проверка регрессии включает
существующий бинарный betting и стратегии клубного 1X2. Независимый reviewer
проверил изменения и после исправления обработки повторного trial не нашёл
блокирующих замечаний.
Первый CI выявил устаревшее ожидание теста: прежний контракт полностью
пропускал betting для 1X2, тогда как новый контракт оценивает рынок через
отдельный 1X2-оценщик. Тест теперь проверяет отключение только бинарных
компонентов и расчёт метрик 1X2 на минимальном матче. После исправления
`make test-unit` завершился: 1 763 passed, 18 deselected.
Повторное независимое review проверило исправленный тест и mypy; проверенный
CI-fix commit: `d504e839f097ada374972cb3ebb78634e55704a9`.

## Не изменено и остаточные риски

Правило стандартных бинарных рынков не менялось. Финансовая оценка использует
исторические коэффициенты Smart Tables без подтверждённого as-of времени;
реализуемость этих ставок в production не доказана.
Старый успешный результат ровно `1e6` без сохранённого агрегата неотличим
от исторического штрафа и не переносится автоматически.
