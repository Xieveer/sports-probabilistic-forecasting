# TASK-040-2 — Две стратегии одного рынка 1X2

> **Статус:** реализация, локальные проверки и review завершены
> **Задача:** [TASK-040-2](../../backlog/tasks/TASK-040-2-winner-model-strategies.md)
> **Требование:** [REQ-040](../../product/requirements/REQ-040-club-football-platform-e2e.md)

## Изменено

Один `winner_1x2` поддерживает long binary с двумя независимыми шансами победы
и проверкой остатка для ничьей, а также wide multiclass с прямыми П1/Х/П2.
Event-level temporal split удерживает стороны матча вместе. Обе стратегии
получили отдельные model identity и локальные shadow-артефакты. Завершённые
кубковые матчи проходят проверку счёта основного времени до обучения.

При интеграционном review уточнены настройки CatBoost для wide 1X2 и запрет
несовместимого бинарного walk-forward; обе футбольные стратегии проверяют
полноту и допустимость счёта. Зависимости DVC ingest включают аудит счёта.

## Фактическая проверка

На одном закреплённом историческом snapshot обе модели обучены с 100 деревьями.
Holdout содержит одинаковые 2 805 событий. Полный 1X2 logloss: long 1.0226,
wide 1.0028; Brier: 0.6121 и 0.5986. У long остаток ничьей в holdout
0.0436…0.4158, отрицательных значений нет. Целевые проверки target, fold,
class mapping и materialize прошли; второй независимый review подтвердил
исправление фолдов Optuna и аудит отрицательного остатка.

Для UCL/UEL сверены все 6 049 строк snapshot: 6 045 допустимых, четыре
технических или неполных результата исключены. Выборка матчей с дополнительным
временем и пенальти сопоставлена с официальным счётом UEFA после 90 минут.

Интеграционная проверка после объединения с актуальным `main`: 117 адресных
тестов футбольных стратегий, целевых меток, карантина и материализации прошли;
`make lint` и `make ai-validate` прошли. Тесты не переобучали сохранённые
исследовательские модели и не переоценивали раскрытый holdout.
