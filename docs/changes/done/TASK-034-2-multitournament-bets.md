## Результат

`/bet_add` получает турнир и ID матча. Закрытый API ищет событие в этом
турнире и выбирает явный ручной рынок по виду спорта. Для футбола доступна
ничья 1X2, для хоккея — победитель с ОТ, для настольного тенниса — победитель
матча. Контекст не создаёт фиктивный прогноз. Турнир виден в карточке и списках,
а `by_tournament` входит в месячный API и `/bet_report`.
