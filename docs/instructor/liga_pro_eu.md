### Liga Pro (eu)
- 'id' - id матча
- 'uts' - время в формате utc
- 'tour_id' - id турнира
- 'tour_timestamp' - дата и время начала турнира utc
- 'tour_datetime' - дата и время начала турнира (MSK)
- 'league_name' - название турнира на русском (мусор)
- 'league_name_en' - название турнира на английском (из названия можно спарсить уровень рейтинга турнира для создания контекстной фичи)
- 'tour_name' - название турнира краткое на русском
- 'tour_place' - название стола (дубль)
- 'tour_is_end' - флаг окончания турнира
- 'datetime' - дата и время начала матча (MSK)
- 'timestamp' - дата и время начала матча utc
- 'tour_match_num' - номер матча в турнире
- 'stage_name' - название стадии group/3rd/final
- 'match_is_end' - флаг окончания матча
- 'home_id' - индификатор домашнего игрока
- 'home_full_name' - полное имя домашнего игрока на русском
- 'home_full_name_en' - полное имя домашнего игрока на английском
- 'home_short_name' - короткое имя домашнего игрока на русском
- 'home_short_name_en' - короткое имя домашнего игрока на английском
- 'home_team_id' - (мусор)
- 'home_team_name' - (мусор)
- 'home_team_name_en' - (мусор)
- 'home_team_short_name' - (мусор)
- 'home_team_short_name_en' - (мусор)
- 'away_id' - индификатор гостевого игрока
- 'away_full_name' - полное имя гостевого игрока на русском
- 'away_full_name_en' - полное имя гостевого игрока на английском
- 'away_short_name' - короткое имя гостевого игрока на русском
- 'away_short_name_en' - короткое имя гостевого игрока на английском
- 'away_team_id' - (мусор)
- 'away_team_name' - (мусор)
- 'away_team_name_en' - (мусор)
- 'away_team_short_name' - (мусор)
- 'away_team_short_name_en' - (мусор)
- 'home_tour_places' - текущее место в турнире домашнего игрока
- 'away_tour_places' - текущее место в турнире гостевого игрока
- 'home_score' - сеты взятые домашним игроком (дубль)
- 'away_score' - сеты взятые гостевым игроком (дубль)
- 'scores' - словарь с полным счетом матча
- 'duration' - продолжительность матча
- 'home_rating' - рейтинг домашнего игрока
- 'away_rating' - рейтинг гостевого игрока
- 'tour_players' - число участников в турнире
- 'tour_matches_sum' - максимальное число матчей в турнире
- 'tour_matches_group_sum' - максимальное число матчей в групповом этапе турнира
- '_hms' - сеты взятые домашним игроком
- '_ams' - сеты взятые гостевым игроком
- '_hmps' - поинты взятые домашним игроком
- '_amps' - поинты взятые гостевым игроком
- '_home_name' - полное имя домашнего игрока на английском
- '_away_name' - полное имя гостевого игрока на английском
- '_home_team' -  (мусор)
- '_away_team' -  (мусор)
- '_tour_name' - название стола (фильтр для сплита по регионам: a18 - евро турнир но в другом городе и игроки не пересекаются с другими столами, a12/a14/a16/a17 - евро турниры)
- 'home_tour_point' - домашние турнирные очки на начало матча
- 'away_tour_point' - гостевые турнирные очки на начало матча
- 'odds_feed - коэффициенты фонбет до начала матча
