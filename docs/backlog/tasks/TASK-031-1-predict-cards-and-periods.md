## Результат и границы

`/predict` показывает отдельные карточки прогнозов за выбранные букмекерские
сутки, с временем МСК, понятным рынком, вероятностями, Pinnacle, Edge, EV и
рекомендациями по исходам. Меню не содержит `/edge` и `/models`; команды
управления показывают реальные доступные циклы. Запись денежных ставок будет
следующим срезом после контракта журнала; её кнопку добавить вместе с ним.

## Критерии приёмки

- [x] Периоды `/predict` совпадают по границам 08:00 МСК с `/upcoming`;
  существующий публичный `hours`-контракт API остаётся совместимым.
- [x] Каждый прогноз отправляется отдельным сообщением; на карточке есть
  время МСК, рынок `winner_withOT`, пары home/away вероятностей, Pinnacle,
  Edge и EV, а также рекомендация по рынку.
- [x] Отсутствие линии или рекомендации показано явно и не блокирует
  будущую запись ставки; два решения по разным рынкам не смешиваются.
- [x] `/predict` предлагает только турнир с регулярной выдачей NHL; `/edge`
  и `/models` отсутствуют в меню, справке и обработчиках.
- [x] `/cycle` не привязан к NHL в Telegram-коде: доступные циклы выбираются
  из control API, пока единственный поддерживаемый — NHL.

## План реализации

1. Red: тесты границ периода и ответа API, включая прежний `hours`.
2. Green: запрос полуоткрытого окна для прогноза через общий календарный контракт.
3. Red/green: тесты отдельных карточек, формата и пустых значений; затем код бота.
4. Red/green: тесты меню и выбора поддерживаемого цикла; затем удаление команд
   и отказ от NHL-хардкода в боте.
5. Документация, адресные проверки, независимый review и отчёт `done`.
