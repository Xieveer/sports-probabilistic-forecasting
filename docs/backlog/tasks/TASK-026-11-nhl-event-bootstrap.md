# TASK-026-11 — Доверенное наполнение NHL events

> **Статус:** done — локальный snapshot и review проверены; server rollout ведётся в TASK-026-10
> **Эпик:** [EPIC-026](../EPIC-026-entity-registry.md)
> **Требование:** [REQ-026 #14](../../product/requirements/REQ-026-entity-registry.md)

## Результат

Локальный владелец может повторяемо добавить project events из официального
NHL schedule, когда команды уже подтверждены в registry, время матча задано
точно в UTC и нет противоречий. Неоднозначные случаи попадают в локальную
очередь review. Источник и решение сохраняются в audit; новый verified snapshot
экспортируется и устанавливается отдельным действием.

## Критерии

1. Dry-run ничего не меняет и показывает распределение по статусам и причинам.
2. Применение создаёт только однозначные события, а повтор не создаёт дубликатов.
3. Истёкшие aliases, выключенные сущности, конфликты и неполные данные требуют
   решения владельца; очередь хранит их идемпотентно.
4. После применения snapshot проходит проверку и разрешает проектные события
   контрольного NHL горизонта по официальным source IDs.
5. Runbook описывает ручной импорт, защиту master и отдельную публикацию;
   букмекерские event IDs не подтверждаются автоматически этим импортом.

## Проверка

Целевые тесты, независимое review, проверка реального горизонта и паритета
локального master/snapshot. Результаты фиксируются в
[отчёте](../../changes/done/TASK-026-11-nhl-event-bootstrap.md).
