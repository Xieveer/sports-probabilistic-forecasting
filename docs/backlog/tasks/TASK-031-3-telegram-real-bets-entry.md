## Результат

Владелец записывает ставку из отдельной карточки прогноза: исход, собственные
деньги/фрибет, сумма, фактический коэффициент Winline, время размещения и
подтверждение. `/bets` показывает открытые записи для ручного расчёта с
фактической выплатой и временем. `/bet_history`, `/bet_correct`, `/bet_audit`
дают список и историю исправлений.

## Критерии

- Кнопка показывается только владельцу в личном чате после сохранения контекста.
- Нет рекомендации или цены Pinnacle — запись Winline всё равно возможна.
- Повтор callback подтверждения использует прежний request ID.
- Фрибет win/void показывает денежное правило без возврата номинала.
- Исправление, чужой пользователь и групповой чат проверяются тестом.
