# TASK-026-8 — Локальный веб-каталог registry

> **Статус:** done
> **Эпик:** [EPIC-026](../EPIC-026-entity-registry.md)
> **Требование:** [REQ-026 #12](../../product/requirements/REQ-026-entity-registry.md)

## Результат

Владелец видит весь локальный registry независимо от очереди кандидатов, находит
сущность, просматривает её обозначения по источникам и исправляет проектное имя
или подтверждённую связь через защищённый loopback веб-интерфейс.

## Критерии

1. Пустая очередь не мешает найти подтверждённую команду и все её обозначения.
2. Переименование сохраняет UUID, требует основание, записывает аудит и отклоняет
   устаревшую ревизию формы.
3. Переназначение подтверждённого обозначения сохраняет исходные данные,
   проверяет тип целевой сущности, требует основание, записывает решение и
   отклоняет устаревшую ревизию формы.
4. Новое состояние входит в следующий проверенный snapshot; ранее созданный
   snapshot не меняется. Сервер не меняется до публикации.
5. Существующие ограничения доступа, CSRF и размера запросов действуют на новые
   операции; HTML экранирует данные источников.

## План и проверка

1. Добавить проваливающиеся HTTP/domain тесты просмотра и исправления.
2. Реализовать ограниченный поиск и detail, затем формы правки с audit/revision.
3. Проверить целевые тесты, lint/type checks и локальный snapshot после правки.
4. Обновить руководство локального review и отчёт `done`; передать на независимое review.

## Результат разработки

- Добавлен локальный каталог с поиском и типовым фильтром, доступный без кандидатов.
- На странице сущности показываются связанные обозначения; проектное имя и
  подтверждённая связь редактируются с основанием, аудитом и optimistic revision.
- HTML-значения экранируются, новые POST используют существующие loopback,
  session, CSRF и ограничение размера запроса.
- Реализация и проверки: [отчёт done](../../changes/done/TASK-026-8-local-registry-catalog.md).
- Независимый review завершён без открытых P0–P2; замечания и повторная
  проверка отражены в [отчёте done](../../changes/done/TASK-026-8-local-registry-catalog.md).

Не входят удаление сущностей, изменение срока действия обозначения и правка
неподтверждённых кандидатов вне существующей очереди.
