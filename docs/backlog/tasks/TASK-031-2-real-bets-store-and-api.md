## Результат

Отдельная ставка Winline в RUB сохраняется с точным фактическим коэффициентом,
суммой, типом средств, временем размещения и контекстом показанной карточки.
Повторный запрос идемпотентен, исправление сохраняет audit и проверяет revision.
Закрытый API не выдаёт чужие ставки и не смешивает их с симуляцией.

## Критерии

- Два добора создают две записи; один request ID создаёт одну.
- Старый контекст карточки сохраняет revision и цену после новой публикации.
- Settlement win/loss/void учитывает денежные выплаты и дату расчёта.
- Исправление, отмена и конфликт revision проверяются тестом.
- SQLite migration и PostgreSQL runtime grants соответствуют ORM и закрытой роли.
