# TASK-040-1 — Каталог и входные данные клубного пула

> **Статус:** done — локальная реализация и независимое review завершены
> **Инициатива:** [EPIC-040](../EPIC-040-club-football-platform-e2e.md)
> **Требование:** [REQ-040](../../product/requirements/REQ-040-club-football-platform-e2e.md)

## Результат

Каталог описывает весь `football_top_leagues` и его девять соревнований как
один модельный пул с одним 1X2 market-spec. До готовности локального E2E
deployment profile не создаётся: он активировал бы плановый Airflow fan-out.
Контракт проверяет состав
исходного CSV и явно сообщает по каждому соревнованию количество завершённых
матчей и покрытие исторической тройки коэффициентов. Отсутствующий код или
неожиданная примесь должны завершать проверку с ошибкой.

## Проверка

- Тесты сначала обнаруживают отсутствие пула и проверяют отклонение
  неполного/лишнего состава.
- Каталог не создаёт scheduled heavy-refresh target для локального пула.
- Локальный запуск на уже собранном файле показывает девять кодов и число строк.
- Иные соревнования и существующие профили каталога не меняют поведения.

## Границы

Задача не обучает модель, не считает ROI и не публикует прогнозы. Каталог не
подтверждает наличие upcoming-событий или право на регулярный API-сбор.

## Результат и evidence

[Отчёт Developer](../../changes/done/TASK-040-1-club-pool-catalog.md) фиксирует
состав 31 625 завершённых матчей, хэш локального CSV, red/green и выполненные
проверки. Независимый Reviewer не нашёл блокирующих findings; следующий срез —
TASK-040-2.
