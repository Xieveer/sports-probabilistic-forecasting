## Наблюдаемый дефект

Ручной Data Cycle v1.2.8 на production завершился
`failed/canonical_freshness_failed`. Локальный first-rollout проходил на
пустой базе и не содержал исторических прогнозов production. Проверка
финальных результатов включала прогнозы, рассчитанные после начала матча,
и требовала для них `finished` даже при `needs_review`.

  успешно, либо документирует следующий подтверждённый дефект.
- [x] Локальный бот с отдельным токеном проверен по критическому
  пользовательскому пути до решения о новом production rollout.
- [ ] Изменение прошло независимое review и релевантные проверки.

## Локальное доказательство quality gate

Backup перед v1.2.8 восстановлен в отдельный PostgreSQL 16 без сети с
лимитом памяти 1 GiB. Агрегатный запрос с deadline 2026-09-27 20:00 UTC
нашёл 1 621 исторический матч с прогнозом: старое правило считало все 1 621
матчем без `finished`; ни один прогноз не был создан до начала матча, поэтому
исправленное правило считает 0 пропущенных результатов. Вывод содержал только
счётчики. Фактический вызов исправленного validator в изолированном Worker
контейнере с лимитом 1 GiB вернул `valid=True`, `expired=0`, `missing=0`.
Worker-срез на полной локальной истории опубликовал 1 838 прогнозов и создал
оба архива. Оба архива прошли локальный S3 sync при лимите 512 MiB после
исправления [TASK-025-24](TASK-025-24-archive-sync-bounded-memory.md).
Изолированный API v1.2.8 под ролью `sf_api_reader` ответил `/ready` 200 и
вернул 198 событий NHL на 30 дней; покрытие снимка имеет статус `stale`.
Владелец подтвердил, что `@SSPredictBot` — отдельный тестовый бот. Одно
контрольное сообщение в единственный разрешённый чат подтверждено Telegram
API (`ok=true`, message ID получен).
Адресные тесты bot calendar/notifications прошли под лимитом 2 GiB: 11 passed.
Изолированный Telegram-bot v1.2.8 запущен под лимитом 384 MiB и через
внутреннюю сеть обращается к локальному API; heartbeat подтвердил доступность
Telegram и API. Contract/lifecycle тесты Data Cycle: 41 passed под лимитом
2 GiB. Владелец отправил `/upcoming` тестовому боту и подтвердил корректный
ответ с календарём NHL. Локальный bot container обработал updates без polling
conflict и API 5xx, оставаясь без OOM.

Связанный локальный run `43d645fe-8c0e-406e-9e7d-ef45da4a9d2f` на полном
фиксированном NHL snapshot завершился terminal `partial_success`: календарь,
quality, predictions, publication и archive_sync — `success`; data_odds —
`partial_success` при явно выключенных odds. Опубликовано 1 838 прогнозов,
оба новых архива remote-verified под лимитом archive-sync 512 MiB. Worker
завершился `exit=0`, `OOMKilled=false` под лимитом 3 GiB. Внешний provider
fetch и exact systemd/Compose wrapper в этом локальном run не запускались.
После terminal status локально поставлен один outbox item тем же producer
методом, который вызывает `finish_run`; bot poller доставил его в тестовый
Telegram через Control API и записал `delivered` за одну попытку. Этот
post-terminal probe проверяет transport/ack; атомарность enqueue в одной
транзакции с `finish_run` покрыта шестью тестами репозитория, включая
PostgreSQL lease race на отдельной временной схеме под лимитом 2 GiB.
Владелец подтвердил получение уведомления и корректный ответ `/cycle_history`
с локальным запуском. `make lint`, `make type-check` и `git diff --check`
прошли с лимитами памяти; production не затронут.
Exact production Compose archive-sync command обнаружил и подтвердил дефект
малого tmpfs; исправление и повторная проверка обоих архивов — в
[TASK-025-25](TASK-025-25-archive-sync-tmpfs.md). Exact systemd wrapper целиком
ещё не проверен. Внешний source-acquirer завершился успешно на копии
локального каталога под лимитом 1 GiB. Связанный Worker на обновлённом
source и весах production-модели остановлен лимитом 3 GiB после валидации
полных train-таблиц; подробности и исправление — в
[TASK-025-26](TASK-025-26-refresh-inference-memory.md). До bounded повторной
проверки свежего цикла выпуск был заблокирован. Исправленный run
`876f0523-3f8c-44b6-95a8-0234b4258fbd` завершился `partial_success` при
явно выключенных odds, опубликовал 1 847 прогнозов и подтвердил оба архива
без OOM. Terminal outbox доставлен тестовому боту.
