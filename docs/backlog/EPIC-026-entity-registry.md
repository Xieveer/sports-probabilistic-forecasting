## Цель и границы

Сопоставлять участников, турниры и события из поддерживаемых источников со стабильными внутренними ID. Первый проверяемый срез — команды NHL API и The Odds API. Не создавать универсальную модель всех спортивных статистик или интерфейс Google Sheets в этом срезе.

## Проверяемый результат

1. `COL` из NHL API и `Colorado Avalanche` из The Odds API разрешаются в один внутренний ID; отображаемое имя можно изменить без смены ID.
2. Неизвестное или неоднозначное имя попадает в очередь проверки и не соединяется с событием автоматически как подтверждённое.
3. После ручного подтверждения тот же алиас разрешается повторно без нового решения, с сохранением источника и факта подтверждения.
4. Существующий NHL-календарь и прогнозная выдача остаются доступны на прежних входах.
