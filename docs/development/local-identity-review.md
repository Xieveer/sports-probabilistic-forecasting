# Локальная очередь связей сущностей

Review UI запускается отдельным приложением и слушает только `127.0.0.1:8765`.
Он не входит в `sports_forecast.service.app` и публичный production API.

## Подготовка и запуск

Явно создать или обновить локальную schema registry:

```bash
uv run python -c 'from pathlib import Path; from sports_forecast.identity import EntityRegistry; EntityRegistry(Path("data/registry/master.sqlite3")).initialize()'
```

Создать локальный секрет с ограниченными правами:

```bash
umask 077
python -c 'import secrets; print(secrets.token_urlsafe(48))' > data/identity-review.secret
chmod 600 data/identity-review.secret
```

Запустить из корня репозитория:

```bash
uv run python -m sports_forecast.identity.review_server --registry data/registry/master.sqlite3 --secret-file data/identity-review.secret --actor owner
```

Открыть `http://127.0.0.1:8765/login` и ввести секрет. Остановить сервер: `Ctrl+C` в
терминале запуска. Сервер намеренно привязан к loopback и не предназначен для
проксирования или доступа из локальной сети.

## Проверка новых событий

Очередь показывает исходное обозначение, источник и основания. Для нового
проектного события выберите действие создания сущности, задайте проектное имя,
найдите и выберите уже созданные турнир, домашнюю и гостевую команды, затем
укажите время начала с часовым поясом. Турнир и команды должны относиться к
тому же виду спорта, команды должны различаться. Событие, его связь с
турниром и командами, аудит и подтверждение кандидата сохраняются одной
транзакцией. Если ввод неверен, ни одна из этих записей не создаётся.

Подтверждённое решение станет доступно серверу после экспорта и публикации
нового полного snapshot; порядок команд описан в
[руководстве публикации](../operations/entity-registry-publication.md).

Если спортивный источник исправил участников ранее связанного события,
сервер передаёт кандидата с основанием о конфликте relation. Откройте его в
очереди, проверьте проектное событие и новые факты источника, затем выберите
исправление relation. Укажите проектное событие, турнир, домашнюю и гостевую
команды и новое время с часовым поясом. Это действие обрабатывает один
кандидат за раз; relation, аудит и закрытие временного кандидата атомарны.
Старое подтверждённое обозначение source event ID сохраняет проектную
идентичность. После решения опубликуйте новый полный snapshot. Пока новая
версия не установлена, сервер не связывает новую линию с устаревшей парой.
