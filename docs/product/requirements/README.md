# Требования к изменениям

В этом каталоге хранятся подтверждённые требования для новой функции, изменения поведения или
существенного дефекта. Создавайте файл из [шаблона](0000-template.md) после интервью с
владельцем продукта. Черновик не передают в архитектуру или реализацию до статуса `confirmed`.

Файл требования — единственный источник бизнес-цели и критериев приёмки; технические решения
в нём не выбираются.
