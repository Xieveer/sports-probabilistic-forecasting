# REQ-045 — Обновление Sol для агентов

> **Статус:** confirmed
> **Владелец продукта:** пользователь проекта
> **Создано и подтверждено:** 2026-10-31
> **Инициатива:** [EPIC-045](../../backlog/EPIC-045-agent-models-61.md)

## Цель

Использовать вышедший `gpt-6.1-sol` в действующих Sol-профилях агентов, сохранив
дешёвую `gpt-6-luna` для небольших задач Business Analyst и Developer.

## Подтверждённое решение

- Главный профиль, default subagent и роли Product Owner, Reviewer, Data Researcher,
  Research Scientist и Operations Agent переходят с `gpt-6-sol` на `gpt-6.1-sol`.
- Business Analyst и Developer остаются на `gpt-6-luna`; Architect остаётся на
  `gpt-6-astra`. Новая `gpt-6.1-terra` не назначается существующей роли.
- Уровни reasoning, sandbox, инструкции ролей и workflow не меняются.

## Критерии приёмки

1. Активные профили и корневой default используют указанную карту моделей.
2. Валидатор принимает эту карту и отклоняет прежний `gpt-6-sol` в активном профиле.
3. Тесты AI-слоя и `make ai-validate` проходят; текущая карта в документации совпадает
   с конфигурацией.

## Границы

Изменение касается только проектных Codex-профилей, валидатора, его тестов и
канонической документации. Оно не меняет спортивные модели, production-сервис,
секреты, параметры API и исторические отчёты о прежнем назначении моделей.

Официальные ID и совместимость уровней reasoning сверены с
[документацией OpenAI](https://developers.openai.com/api/docs/guides/latest-model).
