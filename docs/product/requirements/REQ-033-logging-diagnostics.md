# REQ-033 — Точечная диагностика логов

> **Статус:** confirmed — пользователь согласовал пять рекомендаций 2026-10-11

## Цель

Ускорить расследование сбоев ежедневного цикла и локального NHL-сценария без нового
сервиса логов, зависимости или массовой смены формата сообщений.

## Критерии приёмки

1. Явный уровень логирования из конфигурации применяется после раннего получения логгера;
   повторная настройка не добавляет обработчики и не нарушает stdout-контракт CLI.
2. Отказ бота пользователю вне allowlist виден в логе без полного Telegram `user_id`.
3. Ключевые ошибки Data Cycle содержат безопасные `run_id`, этап и код там, где они
   доступны; произвольные детали исключений не раскрываются.
4. Действующий локальный NHL-скрипт не записывает полный вывод дочернего digest-процесса
   в логи, сохраняя текущий результат в stdout и код завершения.
5. Операционный документ описывает путь от `run_id` и статуса этапа до логов нужного
   процесса и версии образа, а также проверяемый сценарий сбоя.

## Границы

Без JSON-формата для всех логов, дополнительных библиотек, очередей, сервисов и
изменений мониторинга. PR и интеграция откладываются до завершения параллельного релиза.
