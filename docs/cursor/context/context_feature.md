Все ewm проходят по diff_ps and total_ps
После генерации для pl/opp по diff_ps соответсвующие фичи должны превратиться в diff как pl - opp, а pl/opp по total_ps соответсвующие фичи должны остаться как есть. H2H также остаются как есть так как там сразу получается diff и total очных встреч

# CyberHockey
## pl/opp stats
Генерация фичей по контекстам(группировкам) для домашней/гостевой команды
- global (ewm по всем матчам)
- side (ewm с учетом стороны дома/гости)
- match_num (номер матча внутри турнира)
- tour_num (нужно будет сгенерировать дополнительную категориальную фичу из времени начала турнира[ночь, утро, день, вечер или 1,2,3,4])
- form
- team (команда которой играет игрок)

## h2h stats
Генерация фичей по контекстам(группировкам) для очных встреч
- global (ewm по всем матчам)
- side (ewm с учетом стороны дома/гости)
- match_num (номер матча внутри турнира)
- form
- team (команда которой играет игрок)
