## Решение

`test_odds_store.py` (тесты OddsStore, load/save/upsert/дедупликация) был создан в R20.1. В R20.7 добавлены новые тесты в существующий `test_odds_refresh.py` и обновлены fixtures в `test_odds_backfill.py`:

**Новые тесты в `tests/test_odds_refresh.py` (5 шт.):**

1. `test_resolve_path_under_tournament_source_relative_and_absolute` — проверка `resolve_path_under_tournament_source`: относительный путь (стандартный), `None` (default), абсолютный путь (`/var/o.parquet`).
2. `test_odds_runtime_from_nhl_config_paths` — загрузка реального `conf/source/nhl.yaml` через `_odds_runtime_from_source("nhl", "nhl", PROJECT_ROOT)`: проверяет `p_store`, `p_state`, `p_unm`, `min_cov == 70.0`.
3. `test_validate_pinnacle_odds_rejects_out_of_range` — `validate_pinnacle_odds_float_columns` бросает `RuntimeError` при значении `1.0` (ниже нижней границы 1.01).
4. `test_run_odds_refresh_backfill_result_quota_fields` — `run_odds_refresh` с мок-функцией, возвращающей `BackfillRunResult(requests_remaining=42, requests_used=58)`: поля корректно присваиваются в `OddsRefreshResult`.
5. `test_log_source_coverage_warning` — `_log_source_odds_metrics` с source.csv (33% coverage < 50% порог): проверяет наличие WARNING с подстрокой `"min_odds_coverage"` в `caplog.records`.

**Обновления в `tests/test_odds_backfill.py`:**

- `FakeClient` в `test_run_backfill_seasons_and_store_upsert` и `test_run_backfill_range_with_store_non_empty_upserts` дополнен методом `last_quota() → OddsApiQuotaSnapshot(None, None)`: необходимо из-за нового вызова `client.last_quota()` в `run_backfill`.

**Фикстуры (parquet):** тесты создают временный store через `store_mod.save_odds_store()` в `tmp_path`; отдельного статического fixture-файла нет, что соответствует подходу `tmp_path` (pytест-рекомендация).

**Итог:** 22 теста в `test_odds_refresh.py` + `test_odds_backfill.py`, все зелёные. Полный suite: 503 passed.
