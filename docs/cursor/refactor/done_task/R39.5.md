## Решение

В `dag_nhl_morning_refresh.py` после `validate` добавлен `BashOperator` с `task_id="post_refresh_digest"`, тот же пул `SF_REFRESH_POOL` и `pool_slots=1`, цепочка `refresh_nhl_morning >> validate >> post_refresh_digest`. Команда собирается функцией `_build_post_refresh_digest_bash_command`: Jinja через `var.value` читает **на каждый запуск** `SF_TELEGRAM_DIGEST_ENABLE` (skip при `0`/`false`/`no`/`off`, регистронезависимо) и опционально `SF_POST_REFRESH_DIGEST_CMD` (`cd` в `SF_PROJECT_DIR`, затем `bash -lc` с аргументом из `tojson`; иначе `SF_UV_RUN python -m sports_forecast.orchestration.post_refresh_digest` с `--tournament`/`--market`/`--market-spec` из `dag_run.conf`/defaults и `--project-root`). Документация и контракт Variables обновлены в `docs/source/nhl_local_operations.rst`. Контурный тест расширен в `tests/integration/test_orchestration_contour.py` (ребро DAG, наличие шаблона digest и переменной skip).
