# R10.2. get_expected_feature_names / get_actual_feature_names; pipeline без warning

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-03-18
> **Приоритет:** 🟡 Medium
> **Сложность:** Medium

---

## Задача

Исправить `get_feature_names()` так, чтобы итоговая статистика в pipeline отражала реально сгенерированные фичи. Вариант C: разделить на `get_expected_feature_names()` и `get_actual_feature_names(df)`; `get_feature_names()` оставить алиасом для обратной совместимости.

---

## Решение

- **Base:** добавлены `get_expected_feature_names()` (делегирует в `get_feature_names()`) и `get_actual_feature_names(_df)` (по умолчанию возвращает ожидаемый список). Добавлен `get_prefixed_actual_feature_names(df)`.
- **EWM, Count:** переопределены `get_feature_names()` → вызывает `get_expected_feature_names()`; реализованы `get_expected_feature_names()` (полный список по конфигу) и `get_actual_feature_names(df)` с проверкой наличия колонок контекста — пропущенные контексты не включаются.
- **Pipeline:** сбор фичей через `get_prefixed_actual_feature_names(result_df)` вместо `get_prefixed_feature_names()`; блок с warning о расхождении ожидаемого и фактического числа фичей удалён.
- В базовом классе параметр `df` в `get_actual_feature_names` переименован в `_df` (ARG002: не используется в дефолтной реализации).

---

## Изменённые файлы

- `sports_forecast/features/generators/base.py` — новые методы get_expected_feature_names, get_actual_feature_names, get_prefixed_actual_feature_names; в __call__ подсчёт фичей через get_actual_feature_names(result).
- `sports_forecast/features/generators/ewm_generator.py` — get_feature_names как алиас, get_expected_feature_names, get_actual_feature_names(df) с учётом пропущенных контекстов.
- `sports_forecast/features/generators/count_generator.py` — то же для Count.
- `sports_forecast/features/pipeline.py` — использование get_prefixed_actual_feature_names(result_df), удаление warning о расхождении.
- `tests/test_feature_generators.py` — тесты test_actual_vs_expected_feature_names_count, test_actual_vs_expected_feature_names_ewm и сопутствующие правки.
