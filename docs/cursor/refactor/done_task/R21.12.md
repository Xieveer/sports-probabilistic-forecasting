## Решение

- **`client.py`:** Добавлен статический метод `_log_network_response(full_path, *, status, x_requests_remaining, cached)`. Логирует только `path` (без query string → apiKey не попадает в лог), `status` (int или строка `"cache"`), `x-requests-remaining`, `cached=True/False`. Вызывается:
  - при cache-hit (status=`"cache"`, cached=True, quota из `last_quota()`);
  - после каждого HTTP-ответа (cached=False), включая второй ответ при 429-retry.
- **`backfill.py`:**
  - `_backfill_date_range`: лог `"backfill: Day {i}/{total} date={day} quota_remaining={N}"` в начале каждой итерации; `daterange(d0,d1)` материализован в список для корректного подсчёта `total_days`.
  - `_log_backfill_close_payload`: вспомогательная функция; после получения payload логирует `day`, `events_found`, `bookmakers_in_response` (отсортированный список ключей букмекеров из ответа). Вызывается в обоих ветках `backfill_day_frames` (legacy и discovery).
  - `run_backfill`: итоговая сводка `"Backfill done: seasons=…, total_rows=…, quota_used=…, quota_remaining=…"` (заменяет старый частичный лог, работает и при season-режиме, и при date-range).
- **`enrichment.py`:** `extract_bookmaker_row_from_event` — debug-лог `"bookmaker {key} not found in event {home} vs {away}"` при отсутствии букмекера в событии.
- **`tests/test_odds_client.py`:** `test_odds_client_cache_hit` и `test_quota_headers` дополнены `caplog`-ассертами: `cached=True/False`, `status=200`, `x-requests-remaining=42`, `/sports/x/odds` присутствует, `test-key` (apiKey) — отсутствует.
