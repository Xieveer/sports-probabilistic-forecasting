# R13.3. Promote в training_sweep по каждому турниру/эксперименту

> **Статус:** ✅ Выполнено
> **Приоритет:** 🔴 High
> **Сложность:** Medium
> **Выполнено:** 2026-04-02

---

## Решение

`training_sweep` переведён на отдельный promote для каждого турнира через
вспомогательный билдер bash-команды. Вместо единого `--experiment` теперь
выполняется цикл по списку турниров с формированием
`{tournament}__{market_spec}` для каждого вызова promoter.

В команду добавлены fail-fast гарантии: `set -e` и явный `|| exit 1` у вызова
`sports_forecast.deploy.promoter`, чтобы любая ошибка promote немедленно
прерывала задачу.

Добавлены unit-тесты на структуру команды, guard непустого списка турниров и
fail-fast семантику.

- `airflow/dags/dag_training.py` — интеграция билдера команды promote по турнирам.

  циклом по турнирам и fail-fast guards.
