# R21.11 — Snapshot discovery: close-only at T−15 min

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-04-26
> **Родительский эпик:** [R21.md](./R21.md)
> **Приоритет:** 🔴 High

---

## Решение

- **`snapshot_discovery`:** :class:`CloseSnapshotPlan` (`close_iso`, `close_minutes_before`, `reference_commence_time_utc`, `used_legacy_timestamps`); :func:`build_close_snapshot_iso_tminus`; :func:`discover_close_snapshot_for_day` — seed (legacy open time) + при наличии `commence` второй GET на T−N минут; иначе GET по `legacy_close`.
- **`backfill`:** :func:`backfill_day_frames` всегда V3: только `close_snapshot_utc` / `close_minutes_before`; динамика через `discover_close_snapshot_for_day`. **Legacy** — один GET по `backfill.close_snapshot_utc`. Удалены параметр `use_open_close` и CLI `--single-snapshot`.
- **`the_odds_api.yaml`:** `snapshot_discovery.close_t_minus_minutes: 15` (вместо `open_probe_offsets_hours` / `close_margin_hours`).

`discover_snapshots_for_day` / `SnapshotPlan` сохранены для обратной совместимости и существующих тестов R21.4.

**Тесты:** `tests/test_snapshot_discovery.py`, `test_odds_backfill.py`, `test_odds_config.py`.

## Примечание

**HTTP за день (динамика):** до 2 GET (seed + close). Экономия относительно open-probe (3–5) сохраняется. Полная «1 GET/день» в документе R21 — продуктовая цель; требуется иной API/эвристика без seed.
