# R8. Исправить `fillna(0)` для int-колонок в `_apply_dtype_conversion`

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-03-08
> **Приоритет:** 🔴 High
> **Сложность:** Trivial

---

## Проблема

`_apply_dtype_conversion` использовал `fillna(0).astype("int64")` для числовых int-колонок (включая `home_sets`, `away_sets`, `home_points`, `away_points`). Для upcoming-матчей это превращало `NaN`-счёт в `0-0`, что является валидным результатом и искажает downstream-логику.

---

## Решение

Заменено на nullable `Int64` (`pd.Int64Dtype()`), который корректно хранит `<NA>` вместо заполнения нулями.

---

## Изменённые файлы

- `sports_forecast/data/clean.py` — `fillna(0).astype("int64")` → `.astype("Int64")`
