## Решение

Добавлен отдельный Sphinx-документ `docs/source/nhl_local_operations.rst` с пошаговым чеклистом локального запуска: ``make init`` / ``uv sync``, ``make db-init``, ``make api-dev``, ``make docker-up`` (перечень сервисов из Compose), ``make airflow-init`` и ``make airflow-up``, блок переменных из ``.env.example`` (только **имена**, без секретов: ``ODDS_API_KEY``, ``BOT_*`` и др.). Зафиксирована граница ответственности API (нет тяжёлой генерации фич в HTTP) со ссылкой на :download:`service_orchestration_architecture.md`. Добавлены smoke-команды: ``curl`` к ``/health`` и открытие Swagger UI ``/docs`` (через ``xdg-open``). Итоговая таблица сопоставляет цели Makefile с эффектом. Страница включена в toctree с подписью «Операции» в `docs/source/index.rst`.
