# R21.10 — Schema V3: close-only, без `draw` у Pinnacle, 17 колонок

> **Статус:** ✅ Выполнено

> **Родительский эпик:** [R21.md](./R21.md) (фаза 2, остались R21.11–R21.14, R21.9)

## Решение

Реализована **целевая схема OddsStore V3** (17 колонок): только close-рынки, без `open_*` и open-таймингов, без `pinnacle_winner_withOT_draw_*` (2-way Pinnacle), с сохранением `onexbet_winner_draw_close` (3-way). Публичная константа `ODDS_STORE_COLUMNS` указывает на V3; V1/V2 оставлены для миграций.

- **`store.py`:** `ODDS_STORE_COLUMNS_V3`, `migrate_v2_to_v3`, `migrate_v1_to_v3` (V1→V2→V3), детекция/выравнивание при `load_odds_store` / `upsert` / `save`.
- **`enrichment.py`:** `_v3_row_keys_for_profile` (только `*_close`, `has_draw` убирает draw у Pinnacle), `extract_bookmaker_row_from_event` по умолчанию `close` для V3-совместимого пути; legacy `open`/`single` для отдельных сценариев.
- **`validation/schemas.py`:** обновлены плавающие/line поля под V3.

Тесты: `tests/test_odds_store.py`, `test_odds_enrichment.py`, `test_odds_config.py`, `test_odds_refresh.py`, `test_odds_pipeline_v2_integration.py` и др. в линейке odds.

**Коммит:** `feat(odds): R21.10 V3 store schema, V1→V2→V3 migration, close-only extraction`
