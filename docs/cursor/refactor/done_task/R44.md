## Решение

Phase 2 features layer для `football_nationals`: winner (1X2) + total (1.5–4.5). Архитектура по NHL R27/R29 — `create_player_metrics` → diff/total для ST `*_all`, `inject_sport_ewm_generators` по `football.ewm_metrics`, контексты `inseason`/`h2h_inseason` через `rolling_column_aliases.season: season_id`.

- **R44.1** — Interview defaults v1 (architect); таблица ответов в backlog + ADR.
- **R44.2** — `docs/cursor/context/football_features_design.md`: контракт generators, отличия от NHL.
- **R44.3** — `conf/sport/football.yaml`: `ewm_spans [3,10]`, 10 `ewm_metrics`, `inseason` contexts, dtype ST stats.
- **R44.4** — `long_format.create_player_metrics`: football diff/total + `_numeric_series` для str→float bronze.
- **R44.5** — Sport EWM через существующий `inject_sport_ewm_generators` (без нового generator-класса).
- **R44.6** — streak/coach **пропущено** (interview → no/defer).
- **R44.7** — `football_nationals.yaml`: `select_columns` без HT; period=all stats; `odd_*` в interim.
- **R44.8** — `dvc.yaml` multirun + `football_nationals`; `dvc.lock` обновлён (`dvc repro features`).
- **R44.9** — Smoke: 22 868 long rows, ~510 `f_` cols, Pandera processed OK; CI `test_r44_football_advanced_pipeline_smoke.py`.
- **R44.10** — `football.md` features section; `HOW_TO_ADD_NEW_TOURNAMENT.md` ссылка на ADR.

**Исключено v1:** HT/`_1h`, streak, coach/referee, odds в модели, similar-neighbor features.

## Проблема

Phase 1 (R42) и data-fix (R43) готовят **interim** для обучения. Phase 2 — **features layer** для `football_nationals`: winner (1X2) + total (1.5/2.5/3.5/4.5). В `conf/sport/football.yaml` уже есть заготовка `rolling_context_names`, `form_params`, `feature_pipeline.groups` (NHL/streak выключены), но нет `ewm_metrics`, нет football-specific generators, `football_nationals` не в DVC features multirun.
