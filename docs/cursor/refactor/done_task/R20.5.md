## Исходное требование

- `conf/source/nhl.yaml` → секция `odds`: `incremental_buffer_days` (default 3), `max_days_per_refresh` (default 30), `auto_merge` (bool), `store_path` (default `odds/pinnacle_odds.parquet`).
- `conf/bookmaker/the_odds_api.yaml` → `quota_budget_per_run` (default 100), `seasons` list.
- Документировать все новые ключи docstring-ами в YAML.

---

## Решение

В `conf/source/nhl.yaml` раздел `odds` расширен тремя новыми ключами с YAML-комментариями:

- `store_path: odds/pinnacle_odds.parquet` — относительный путь к Parquet store (к `data/source/<tournament>/`).
- `state_path: odds/refresh_state.json` — JSON checkpoint для resume.
- `unmatched_report_path: odds/unmatched_teams.csv` — отчёт несоответствий по командам.
- `min_odds_coverage_pct: 70.0` — порог coverage для WARNING (перенесён из R20.6).

Ранее существовавшие `incremental_buffer_days`, `max_days_per_refresh`, `auto_merge` уже присутствовали (добавлены в R20.4); в R20.5 уточнён header-комментарий раздела: добавлено пояснение, что пути `store/state/unmatched` относительные.

В `conf/bookmaker/the_odds_api.yaml` обновлены doc-комментарии для `quota_budget_per_run` и `seasons`: расширены пояснениями о работе с `BackfillRunResult`, graceful stop, ISO-датах и применении при пустом `OddsStore`.
