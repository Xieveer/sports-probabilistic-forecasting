# R21.7 — Валидация + Pandera V2 (multi-bookmaker, total_line, timing)

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-04-25
> **Приоритет:** 🔴 High
> **Сложность:** Medium

---

## Задача

Расширить Pandera-валидацию odds-данных для R21 (V2 store): покрыть все decimal-колонки Pinnacle и 1xBet, добавить проверки диапазона для total_line (point) и столбцов `*_minutes_before`, сохранив backward-compatible alias для V1 API.

---

## Решение

- Функция `validate_odds_float_columns` заменила `validate_pinnacle_odds_float_columns` как основной публичный entry-point. Старое имя сохранено как thin alias (backward compat).
- Введены три группы колонок:
  - `_ODDS_DECIMAL_COLS` — union V1 + V2 decimal (winner home/away/draw + over/under) без total_line; диапазон `[1.01, 100.0]`;
  - `_ODDS_V2_TOTAL_LINE_COLS` — `*_line_*` колонки; диапазон `[0.5, 20.0]`;
  - `_ODDS_MINUTES_BEFORE_COLS` — `open_minutes_before`, `close_minutes_before`; условие `>= 0`.
- Каждая группа представлена переиспользуемым Column-объектом (`_OddsDecimalColumn`, `_OddsTotalLineColumn`, `_OddsMinutesColumn`) и подсхема собирается динамически по присутствующим в df колонкам.
- `backfill._upsert_if_non_empty`: call-site переключён на `validate_odds_float_columns` — fail-fast до записи parquet (V2-колонки теперь покрыты проверкой).
- `refresh.run_odds_refresh`: call-site переключён + добавлен `_log_store_odds_post_validate` — per-bookmaker coverage-метрики в лог после успешной валидации store.
