# R37.2. Репозиторий и HTTP: окно предстоящих прогнозов (48h UTC)

## Решение

В `PredictionRepository.get_upcoming_predictions` добавлены опорное время UTC (`datetime.now(timezone.utc)` или `now_utc` для тестов), длительность окна `hours` (по умолчанию 48), фильтр `match_datetime` в диапазоне `[now, now + hours]` с приведением к naive UTC через `_utc_naive_for_query` для согласованности с SQLite/витриной; строки без `match_datetime` исключаются (`isnot(None)`). Добавлен опциональный фильтр по `market_spec`. В роутере `GET /predict/upcoming/{tournament}` проброшены Query-параметры `hours` (1–8760), `market_spec`, расширены описания `market` для OpenAPI (NHL: `winner` vs полный матч `winner_withOT`, ссылка на `conf/market`). Юнит-тесты: окно 48h, исключение прошлых матчей, фильтр `market_spec`.

**Зафиксированное поведение по умолчанию:** окно 48 часов от текущего UTC (ранее без верхней границы по времени); клиентам, нужен больший горизонт, следует увеличить `hours`.
