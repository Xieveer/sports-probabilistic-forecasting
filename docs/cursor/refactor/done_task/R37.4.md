## Решение

Добавлен модуль `sports_forecast/data/providers/odds/live_nhl_pinnacle.py`: один вызов `OddsApiClient.fetch_odds_for_sport` (рынок `h2h`, регион из конфига) → разбор Pinnacle через существующие хелперы enrichment → сопоставление котировок с `match_id` витрины. В `conf/bookmaker/the_odds_api.yaml` — узел `live_inference`: `max_real_http_requests` (пробрасывается в `OddsApiClient` через `build_odds_client_for_live`), `regions`, `commence_tolerance_minutes`, явный `event_id_to_match_id`. Маппинг: сначала overrides по id события API, затем fuzzy по каноническим именам команд (`TeamNameRegistry` / `normalize_team_key`) и близости `commence_time` в пределах tolerance; при неоднозначности без времени старта — `None`. Отсутствие букмекера/обеих цен в h2h даёт пропуск события в списке котировок или `None` в результате по матчу. Логи только `debug` по id/матчам, без секретов. Тесты: фикстурный JSON, mock-клиент без сети, квота `max_real_http_requests`, границы tolerance.
