# R39.3 — Контракт текста одного Telegram digest (post-refresh)

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-05-13
> **Приоритет:** 🔴 High (в составе эпика R39)
> **Сложность:** Low

---

## Решение

Добавлен модуль `sports_forecast.orchestration.digest_message`: чистая сборка **одной** русскоязычной строки для Telegram без HTTP/`sendMessage`. В модульном docstring зафиксирован контракт блоков (предупреждения `odds_warning`, опциональный `header`, счётчик матчей, provenance, топ по |edge| с устойчивой сортировкой, краткий список с лимитом 5 строк + «… ещё K»), обрезка по `max_chars` с суффиксом «… [обрезано до N символов]».

Публичный API: `DigestMatchLine`, `build_post_refresh_digest_text`, `format_provenance_from_deploy_dict`. Golden-тесты в `tests/test_digest_message.py` фиксируют эталонный вывод для нескольких матчей, ветку `missing_api_key` и усечение длины.
