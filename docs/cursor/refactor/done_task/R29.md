# R29. Спорт-осознанная композиция feature pipeline (streak, NHL pre-gen, будущие виды спорта)

> **Статус:** ✅ Выполнено
> **Приоритет:** 🔴 High
> **Сложность:** Medium
> **Выполнено:** 2026-05-04

---

## Проблема

1. Профиль **`features=advanced`** жёстко тянул **одинаковый** набор генераторов для **всех** турниров: `time`, три **NHL** pre-gen (`nhl_schedule`, `nhl_standings`, `nhl_roster`), **`streak`**, `form`, rolling.
2. Для **киберхоккея** и **настольного тенниса** NHL-блоки и streak вызывались несмотря на несогласованность с продуктовым намерением «streak пока только NHL».
3. Без явного контракта «какие генераторы допустимы для какого `sport`» техдолг и путаница в логах накапливались.

---

## Решение

Реализована трёхслойная система композиции `generators`:

1. **Пресет `features=*`** — общий каркас (`time`, `form`, `rolling`/EWM/Count). Не содержит NHL pre-gen и streak для всех спортов.
2. **`conf/sport/<sport>.yaml`** — канонические группы optional-генераторов (`feature_pipeline.groups.nhl_boxscore`, `feature_pipeline.groups.streak`).
3. **`conf/tournament/<tournament>.yaml`** — только диффы (`feature_pipeline_overrides`): переключение групп (`groups`), явное исключение ключей (`exclude_generators`).

Композиция выполняется функцией `compose_feature_pipeline` вызываемой в начале `materialize_features_config` (до `expand_rolling_generators_inplace`).
