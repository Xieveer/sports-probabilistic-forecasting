## Решение

В `data_refresh` DAG добавлен отдельный шаг `validate` после `features` с запуском
`python -m sports_forecast.validation.run_validation` через `BashOperator`.
Цепочка зависимостей обновлена до `ingest → clean → features → validate`, что фиксирует
fail-fast контракт: при падении любого upstream-этапа downstream не запускаются, а при
ошибке `validate` DAG завершается с ошибкой.
