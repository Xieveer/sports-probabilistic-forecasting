## Решение

### R23.1 — `.github/workflows/ci.yml`
Matrix Python 3.10/3.12, `astral-sh/setup-uv@v5` с GHA-кешем, `uv sync --frozen --group dev`, `make lint`, `make test-unit`. Concurrency group с `cancel-in-progress: true` на PR. Lint и 596 unit-тестов проходят.

### R23.2 — `.github/workflows/docker.yml`
Multi-stage build matrix: `api`, `worker`, `telegram-bot` из единого `Dockerfile` (target). Push в `ghcr.io` на merge в `main` и `workflow_dispatch`. Теги `sha` (commitish) + `latest` через `docker/metadata-action`. Кеш GHA layer (`cache-from/to: type=gha`). Без отдельного GHCR_TOKEN — только встроенный `GITHUB_TOKEN` с `packages: write`.

### R23.3 — `.env.example` + `docs/deploy/secrets.md`
`.env.example` содержит все секретные/конфигурационные переменные: `POSTGRES_PASSWORD`, `SF_*_IMAGE`, `SF_API_DOMAIN`, `GRAFANA_*`, `BOT_TOKEN`, `BOT_ALLOWED_USER_IDS`, `ODDS_API_KEY`, `MLFLOW_TRACKING_URI`, `SF_REFRESH_*`. Закомментированные опциональные переменные с примерами. `docs/deploy/secrets.md` — таблицы GitHub Secrets/Variables для деплоя, инструкция по basic auth за Caddy, ссылки на связанные файлы. Файл `.env` уже в `.gitignore` (строка 47).

### R23.4 — `.github/workflows/deploy.yml`
SSH-деплой через `appleboy/ssh-action@v1.2.0`. Триггер: `workflow_dispatch` (ручной) + `workflow_run` от успешного `Docker` на `main`. Secrets: `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`; Variable: `DEPLOY_PROJECT_DIR` (fallback `/opt/sports-forecast`). Скрипт: `docker compose -f docker-compose.yml -f docker-compose.prod.yml pull && up -d --remove-orphans`. Concurrency `cancel-in-progress: false` — деплой не прерывается.

### R23.5 — `docker-compose.prod.yml`
Production override-файл (Compose Merge). Сервисы `api`, `worker`, `telegram-bot`, `mlflow`, `prometheus`, `grafana`, `db` — CPU/mem limits, `pull_policy: always`, `ports: !reset []` (закрыты внутрь, только через Caddy наружу). Единый `&prod_logging` YAML anchor: `json-file`, `max-size 10m`, `max-file 3`. Два новых сервиса: `node-exporter` (prom/node-exporter:v1.8.2, pid: host, `/:/host:ro,rslave`) и `caddy`. Комментарий с оценкой ресурсов: 2 vCPU/4 GB для inference-only, 4 vCPU/8 GB с refresh/train. Volumes: `caddy_data`, `caddy_config`. Pre-commit hook `check-yaml` дополнен исключением `docker-compose.prod.yml` (тег `!reset` — Compose extension, не стандартный YAML).

### R23.6 — `deploy/Caddyfile`
Caddy 2.8-alpine. Обязательный блок `{$SF_API_DOMAIN}`: gzip/zstd, `reverse_proxy api:8000`, Let's Encrypt автоматически. Раскомментируемые блоки для `{$SF_GRAFANA_DOMAIN}` и `{$SF_MLFLOW_DOMAIN}` с `basicauth` через env-переменные (инструкция в `docs/deploy/secrets.md`).

### R23.7 — Observability production
- `monitoring/prometheus/prometheus.prod.yml`: `scrape_interval: 30s`, jobs `sports-forecast-api`, `mlflow`, `node` (node-exporter:9100). Монтируется в prod вместо dev-конфига.
- `monitoring/prometheus/alert_rules.yml` — новая группа `api_slo`: `HighPredictionLatencyP99` (p99 > 1s, 5m), `PredictionMaterializeStale` (freshness > 12h, 1h), `RootDiskLow` (disk < 10%, 30m, critical).
- `monitoring/grafana/provisioning/datasources/datasource.yml` — добавлен `uid: prometheus` для консистентных ссылок из dashboards.
- `monitoring/grafana/dashboards/sports_forecast.json` — две новые панели в row y=28: «Last materialize age (s)» (thresholds 0/6h/12h) и «Host root FS free %» (node_filesystem, thresholds 0%/10%/15%).

### R23.8 — `sports_forecast/orchestration/cron_refresh.py`
CLI-entrypoint на `argparse` (все параметры через env или аргументы: `--tournaments`, `--project-dir`, `--uv-run`, `--features`, `--market`, `--market-spec`, `--lock-file`, `--lock-wait-seconds`, `--source-cmd`, `--dry-run`). Делегирует сборку команды в `build_refresh_per_tournament_command` (единый контракт с Airflow DAG). `scripts/cron/nhl_data_refresh.sh` — тонкая обёртка с `set -euo pipefail` и `exec uv run python -m …`. Cron-пример в docstring. Unit-тесты: `tests/test_cron_refresh.py` (2 теста: dry-run содержит flock+nhl+source_refresh; custom lock-file). `tests/conftest.py` — auto-attach marker `unit` к тестам без slow/integration-меток.
