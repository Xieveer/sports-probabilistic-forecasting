## Проблема

R19/R20 реализовали odds-пайплайн для **одного** букмекера (Pinnacle) с **фиксированными** UTC-timestamps снимков (12:00, 23:30) и **без** хранения базы тотала (point/line). R21.1–R21.8 реализовали V2 schema (33 колонки, open+close, draw_withOT, multi-bookmaker). **После проверки данных (2026-04-25) выявлено:**

1. **`draw_withOT` не имеет физического смысла** — Pinnacle NHL h2h = 2-way (no draw in OT market). Колонки `pinnacle_winner_withOT_draw_{open,close}` всегда NULL. Убрать из схемы.
2. **Open-line не нужна сейчас** — для MVP достаточно close-линии. Open-line per bookmaker (букмекеры появляются в разное время) — будущая доработка.
3. **Close-only at T-15min** — один снимок за 15 мин до `commence_time`. Убирает open-probe schedule (экономия 2–4 API calls/день, упрощение логики).
4. **Недостаточно логов** при обращении к API — нужен прогресс (день X/N, квота, events found).
5. **Team-name registry** — сопоставление `NHL source` (3-буквенные коды) и нормализованных имён The Odds API: ручной маппинг в `conf/bookmaker/team_name_registry/nhl.yaml` (32 команды + `odds_api` алиасы). Краевой кейс: **UTA** — в API могут встречаться **два** разных нормализованных имени → **два** ключа `odds_api: … → UTA`. После свежей полной перезаливки при необходимости доразметить остаток по `data/source/nhl/odds/unmatched_teams.csv`.

## Архитектурные решения

### 1. Close-only snapshot at T-15min

Один API-запрос на день: `commence_time - 15min`. Все bookmakers из одного ответа.
- `close_snapshot_utc` — фактический ISO момента запроса.
- `close_minutes_before` ≈ 15 (может отличаться, если несколько матчей в день с разным `commence_time`).
- **Open-line отложена**: в будущем per-bookmaker open (1xBet может появиться позже Pinnacle) → отдельная задача вне R21.

```yaml
snapshot_discovery:
  close_t_minus_minutes: 15   # V3: заменяет open_probe_offsets_hours + close_margin_hours
```

### 2. Naming contract — market semantics in column names (без изменений от V2)

- `winner` / `total` = regulation only;
- `winner_withOT` / `total_withOT` = full game (OT/SO included).

Для NHL: `onexbet` → `winner` / `total`; `pinnacle` → `winner_withOT` / `total_withOT`.

### 3. draw_withOT — убрано

Pinnacle NHL h2h = 2-way (home, away). Draw в OT-рынке не существует. Колонка `pinnacle_winner_withOT_draw_close` удалена из V3.

1xBet h2h = 3-way (home, away, draw) → `onexbet_winner_draw_close` **остаётся**.

Поле `has_draw` в `BookmakerExtractionProfile` теперь **активно используется** для генерации/фильтрации колонок (ранее не фильтровало).

### 4. Dedup keys

`ODDS_DEDUP_KEYS = ("game_date", "home_team_norm", "away_team_norm")` — без изменений.
