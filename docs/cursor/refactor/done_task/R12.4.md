## Решение

Выполнено обучение по **market=winner** для **двух турниров**: киберхоккей **uel_kz_1**, настольный теннис **lp_ru**. Проверен полный набор алгоритмов **catboost, lgbm, logreg, stacking** на **полном наборе фичей** (`conf/features/advanced.yaml` → `features=advanced`).

Запуск: Hydra multirun (8 прогонов):

`uv run python -m sports_forecast.train --multirun tournament=uel_kz_1,lp_ru market=winner market_spec=winner algorithm=catboost,lgbm,logreg,stacking features=advanced`

Метрики зафиксированы в MLflow (эксперименты `uel_kz_1__winner__player`, `lp_ru__winner__player`), в тегах run указано `featureset=advanced` и `algorithm`.

Ранее был отдельный прогон «1-й»: uel_kz_1 + catboost + basic (`make train`); он заменён/дополнен этой финальной проверкой.

Недочёты и предупреждения по пайплайну см. в `docs/cursor/refactor/issues-winner-full-cycle.md` (в т.ч. запись о частично обрезанном логе multirun при первой попытке; фактическое завершение 8 прогонов подтверждено MLflow и пользователем).
