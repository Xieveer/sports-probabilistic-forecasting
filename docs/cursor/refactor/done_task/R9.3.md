## Стало

```python
for col in score_cols:
    merged[col] = merged[col].fillna(merged[col].min())
merged[score_cols] = merged[score_cols].fillna(0.0)  # fallback
```

---

## Решение

`fillna(0.0)` → `fillna(per_column_min)`. Согласовано с подходом для рангов (`fillna(max_rank)`): отсутствие в ранкере = худший наблюдаемый score данного метода. Применено в двух местах: `_aggregate_rank_average()` и `_build_aggregated_df()`.
