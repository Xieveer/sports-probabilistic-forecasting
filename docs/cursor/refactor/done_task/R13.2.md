# R13.2. Явный прод-контракт materialize через promoted-артефакт

## Решение

Для `materialize(prod)` введён явный контракт promoted-модели: чтение
`models/{tournament}/{market_spec}/best/deploy.yaml` и использование
`model.algorithm`/`model.featureset` из метаданных promote вместо опоры на
`algorithm/features` из переменных DAG.

В DAG materialize убраны переменные `SF_MATERIALIZE_ALGORITHM` и
`SF_MATERIALIZE_FEATURES`: оркестрация передаёт только турнир/рынок/specific market,
а выбор прод-модели теперь централизован в promoted-артефакте.

Добавлены unit-тесты, которые подтверждают:
- успешный `prod`-путь с чтением `deploy.yaml` и корректной передачей algorithm/featureset;
- fail-fast поведение при отсутствии deploy-контракта.
