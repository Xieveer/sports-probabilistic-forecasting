# R21.4 — Snapshot discovery: динамический алгоритм open/close

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-04-25
> **Приоритет:** 🔴 High
> **Сложность:** Medium

---

## Описание задачи

Реализовать standalone-модуль динамического выбора ISO-снимков open/close для backfill:
- `SnapshotPlan` — dataclass результата (open/close ISO, minutes_before, legacy-флаг).
- `discover_snapshots_for_day` — probe-алгоритм: seed-запрос → `min(commence_time)` → close/open по смещениям → legacy-fallback.
- Без интеграции в `backfill.py` (R21.5).

---

## Решение

**`SnapshotPlan` (frozen dataclass, slots)**
— результат discovery: `open_iso`, `close_iso`, `open_minutes_before`, `close_minutes_before`, `reference_commence_time_utc`, `used_legacy_timestamps`. Иммутабельный, hashable.

**`HistoricalOddsClient` (Protocol, `@runtime_checkable`)**
— минимальный контракт клиента: только `fetch_odds_for_sport`. Отделяет модуль от `OddsApiClient`, упрощает тестирование через моки без наследования.

**Вспомогательные функции**
- `_as_utc_datetime` — нормализует ISO-строку в `datetime(tz=UTC)`, включая `Z`-суффикс.
- `parse_commence_utc_from_event` — читает `commence_time` / `commenceTime` из события.
- `commence_datetimes_utc_on_day` — фильтрует события по календарному дню (UTC).
- `build_close_snapshot_iso` — `min(commence) − close_margin_hours` → ISO Z.
- `minutes_before_commence` — `max(0, (ref − snap).total_seconds() // 60)`, неотрицательно.
- `to_api_iso_z` — ISO с суффиксом `Z`, без микросекунд.
- `_legacy_isos` — собирает `{day}T{HH:MM:SS}Z` для fallback.

**`discover_snapshots_for_day`**
Алгоритм:
1. Seed-запрос в `legacy_open_time_utc` (как в R20 backfill) — извлекает `min(commence_time)` матчей дня.
2. Если `ref_dt` найден:
   - `close_iso = ref_dt − close_margin_hours`; запрос close-payload.
   - Probe open: offsets по убыванию (168h → 72h → 24h), первый ответ с событиями дня → `open_iso`.
   - Если все пробы пусты → `open_iso = legacy_o`, `open_minutes_before` вычислен от реального `ref_dt`, `used_legacy=True`.
3. Если `ref_dt` не найден (нет событий в seed): оба ISO из legacy fixed times, `minutes_before=0`, `used_legacy=True`.
4. Исключения в seed/probe перехватываются (`BLE001`), логируются, не прерывают flow.
