## Решение

В архитектурной документации зафиксирован operational-контракт DVC по средам
`prod/dev/CI` с явными runtime-границами:

- где допустимы прямые вызовы модулей;
- где обязателен `dvc repro`;
- как выполняется синхронизация артефактов между runtime-контурами и инженерным контуром.

Добавлена матрица по средам и правило консистентности для случаев, когда в `prod`
используются прямые вызовы без `dvc repro`: состояние не считается воспроизводимым,
пока артефакты не синхронизированы через DVC remote и не зафиксированы в git/DVC-метаданных.
