# R27. NHL Feature Engineering v2 — расширенный набор фичей

> **Статус:** ✅ Выполнено
> **Приоритет:** 🔴 High
> **Сложность:** High
> **Выполнено:** 2026-05-04

---

## Проблема

Текущий набор фичей (195 `f_`-колонок) покрывал базовые EWM по `diff_ps`/`total_ps`,
форму, расписание, таблицу, ростер и время. Отсутствовали: target-aware EWM по голам,
EWM по хоккейной статистике, streak-фичи, внутрисезонный контекст, lineup-сигналы.

---

## Решение

Реализованы пять фаз задачи:

### Phase 1 — Derived metric columns (R27.1 + R27.6)

- `sports_forecast/features/long_format.py`: добавлены `_diff_pair` / `_sum_pair` хелперы;
  `create_player_metrics` теперь вычисляет `goals_full_diff`, `goals_full_total`,
  `goals_reg_diff`, `goals_reg_total`, `sog_diff_ft`, `bs_diff_ft`, `hits_diff_ft`,
  `pim2_diff_ft`, `fow_diff_ft`. Пропуск с `logger.debug` если нужных колонок нет.
- `conf/features/_common.yaml`: все новые метрики добавлены в `create_metrics`,
  `result_cols` и сырые pl/opp-колонки; `season` добавлен в `long_format_context_columns`.
- `conf/features/generators/rolling/standard.yaml`: spans `[5, 25, 100]` → `[5, 15]`
  в ewm_diff и ewm_total.

### Phase 2 — Sport-level EWM (R27.2 + R27.3)

- `conf/sport/ice_hockey.yaml`: добавлены `ewm_spans: [5, 15]`,
  `ewm_metrics` (7 записей: gf_diff, gf_total, sog, bs, hits, pim2, fow),
  `season_start_month: 9`.
- `sports_forecast/features/rolling_contexts.py`: реализованы
  `_tournament_ewm_metrics`, `_tournament_ewm_spans`, `inject_sport_ewm_generators`.
  Функция клонирует шаблоны `ewm_diff`/`ewm_total` (с развёрнутыми контекстами)
  для каждой записи `sport.ewm_metrics`, создавая `ewm_sport_{label}` генераторы
  с `warmup.enabled=False`. Вызывается из `materialize_features_config`.

### Phase 3 — Streak (R27.5)

- `sports_forecast/features/generators/streak_generator.py`:
  `StreakFeatureGenerator` — pre-match серии (win/lose streak), `streak_diff`,
  rolling win-rate за N матчей. Хронологический обход: одна строка на матч
  (side=h), shift=1 гарантирован логикой (состояние обновляется после записи).
  `win_mode`: `goals_full` с fallback на `points` если колонок нет.
- `conf/features/generators/streak/default.yaml`: `win_mode: goals_full`,
  `win_rate_windows: [5, 10]`.
- `sports_forecast/features/pipeline.py`: `GENERATOR_MAP["streak"]` зарегистрирован.
- `conf/features/advanced.yaml`: `generators/streak@generators: default` добавлен
  перед rolling; description обновлён.

### Phase 5 — Lineup features (R27.9)

- `sports_forecast/features/generators/roster_generator.py`:
  `_add_lineup_features()` — вычисляет для home и away:
  - `lineup_continuity` (Jaccard номеров свитеров current vs prev матч),
  - `roster_mean_seniority` / `roster_min_seniority` (среднее/мин. накопленных
    выходов игроков состава до матча),
  - `roster_stability` (mean continuity за `stability_window` матчей).
  Отдельные хелперы `_roster_sweater_set` и `_jaccard_sweaters`.
  Управляется флагом `lineup_features_enabled`.
- `conf/features/generators/roster/nhl.yaml`: добавлены `lineup_features_enabled: true`,
  `stability_window: 5`.

### Phase 4 (R27.7) — выполнена ранее в R28.2 (inseason context).

### Phase 6 — R27.10 smoke (CI, 2026-05-04 follow-up)

- Исправлен баг: `_tournament_ewm_metrics` / `_tournament_ewm_spans` не распознавали
  `ewm_metrics` / `ewm_spans` из **OmegaConf ListConfig** (типичный `cfg.tournament` из Hydra),
  из‑за чего `inject_sport_ewm_generators` молча не срабатывал в `features_build` / train.
  Нормализация через `OmegaConf.is_config` + `to_container`.
- `tests/test_r27_nhl_advanced_pipeline_smoke.py`: compose `tournament=nhl` + `features=advanced`,
  synthetic wide → `FeaturePipeline` (≥400 `f_`, наличие inseason + sport EWM по `gf_diff`).
- `tests/test_rolling_contexts.py`: `test_tournament_ewm_metrics_accepts_omegaconf_listconfig`.

Операционный прогон на полном `matches_interim.parquet` остаётся по желанию локально
(репозиторий без data/).

## Результат

- 617+ тестов проходят, linter-ошибок нет.
- Новые фичи покрывают: goals_full-EWM (R27.2/3), stats-EWM (sog/bs/hits/pim2/fow),
  streak/win-rate (R27.5), lineup continuity/seniority/stability (R27.9).
- Архитектура: sport-level конфиг определяет *что*, generic `standard.yaml` — *как*;
  inject-функция связывает их без изменения EWMFeatureGenerator.
