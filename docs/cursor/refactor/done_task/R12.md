## Решение

Эпик закрыт: воспроизводимый цикл winner для uel_kz_1 и lp_ru отработан, включая продвинутые фичи и stacking. MLflow-эксперименты именуются **`{tournament}__winner__player`**. Для materialize выбрана лучшая по `test_logloss` пара среди advanced-прогонов — **logreg + advanced**. При записи в SQLite выявлено отставание схемы от ORM (`model_tag`); добавлена точечная миграция в `init_db` для существующих SQLite-БД без полной пересборки таблицы.
