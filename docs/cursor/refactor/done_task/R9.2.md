## Было

```python
X_filled = X.fillna(0)
```

---

## Стало

```python
X_filled = X.fillna(X.median()).fillna(0.0)  # median + fallback for all-NaN
```

---

## Решение

`fillna(0)` → `fillna(X.median())`. Медиана устойчива к выбросам и не смешивает «нет данных» с «нулевой показатель». Fallback `fillna(0.0)` для теоретически возможных полностью NaN-колонок. Добавлено логирование при >0% NaN.
