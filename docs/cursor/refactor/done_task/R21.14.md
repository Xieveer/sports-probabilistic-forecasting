## Решение

Финализация поддержки V3 schema в тестах, конфиге и валидации. Выполнялась поэтапно:

- **R21.10/R21.11** закрыли большинство тестовых обновлений (`test_odds_store.py`, `test_odds_enrichment.py`, `test_snapshot_discovery.py`, `test_odds_config.py`) — тесты V3 store, close-only extraction, `has_draw` filtering, auto-detect V1→V2→V3.
- **Данный коммит** закрыл оставшиеся пункты R21.14:
  - **`snapshot_discovery.py`:** добавлена `_safe_fetch_exception_detail(exc)` — WARNING-логи при `seed fetch failed` выводят только тип исключения + HTTP status (если есть), без полного URL/query-строки. Устраняет утечку `apiKey` в логи, зафиксированную в R21.12 reviewer-tech-debt.
  - **`validation/schemas.py`:** Pandera-схема переименована `OddsStoreNumericV2` → `OddsStoreNumericV1V2V3`; описание уточнено как «V1/V2/V3 union, nullable». Отражает реальный охват union-колонок (decimal, total_line, minutes_before из всех трёх версий).
  - **`the_odds_api.yaml`:** Обновлены комментарии: V3 canonical columns (`ODDS_STORE_COLUMNS_V3`/`ODDS_STORE_COLUMNS`), `bookmaker_profiles` описание, `output_columns` помечены как legacy R19/R20.
  - **`tests/test_odds_store.py`:** переименован `test_save_accepts_v1_input_writes_v2` → `test_save_accepts_v1_input_writes_v3` (test-name соответствует фактическому поведению: V1 input → V3 store).
  - **`tests/test_validation.py`:** добавлен `TestValidateOddsFloatColumnsV3::test_v3_positive_sample` — позитивный тест валидации всех 11 float-колонок V3 store (Pinnacle + 1xBet close-only, `close_minutes_before`).

129 тестов проходят.

## Ограничения и принятые компромиссы

- `_ODDS_MINUTES_BEFORE_COLS` в Pandera по-прежнему содержит `"open_minutes_before"` для backward-compat V1/V2. В V3 store эта колонка отсутствует → Pandera пропускает её (`strict=False`). Убрать можно после полного перехода на V3 store (R21.9 backfill), когда V1/V2 store больше не загружаются.
- `_events_to_odds_frame_v2` в `enrichment.py` содержит суффикс `_v2` в имени, хотя обрабатывает V3-поток. До R21.9 функциональных последствий нет — техдолг зафиксирован.
- Тест `test_v3_positive_sample` проверяет только positive path (valid data). Тест negative path (недопустимые значения для V3 store) не добавлен — покрыт существующими V1/V2 negative тестами в `TestValidateOddsFloatColumnsV2`.
