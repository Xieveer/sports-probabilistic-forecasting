# R20.2 — Season-aware конфигурация + расширение CLI backfill для multi-season

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-04-25
> **Приоритет:** 🔴 High
> **Сложность:** High

---

## Исходное требование

- В `conf/bookmaker/the_odds_api.yaml` добавить секцию `seasons` со списком `{name, date_from, date_to}` для NHL (2023-24, 2024-25, 2025-26).
- В `backfill.py` добавить параметр `--seasons N` (N последних сезонов из конфига) как альтернативу `--from/--to`.
- Добавить `--store`/`--tournament` флаг: результат сохраняется через `OddsStore.upsert()` (R20.1).
- Добавить `quota_budget_per_run` в конфиг: при исчерпании бюджета — graceful stop с логированием прогресса.

---

## Решение

### conf/bookmaker/the_odds_api.yaml

Добавлены два новых ключа верхнего уровня:

- **`quota_budget_per_run: 100`** — лимит реальных HTTP-запросов за один CLI-run (0 = без лимита).
- **`seasons.nhl`** — список трёх сезонов с полями `name`, `date_from`, `date_to`.

### client.py

- Добавлен класс `QuotaBudgetError(RuntimeError)` — исключение при исчерпании бюджета.
- `OddsApiClient.__init__` принимает `max_real_http_requests: int | None`.
- Счётчик `_real_http_requests` инкрементируется после каждого успешного сетевого GET (кэш не считается). После 429-retry счётчик также увеличивается.
- Перед следующим HTTP-запросом проверяется `_real_http_requests >= max_real_http_requests`; при достижении поднимается `QuotaBudgetError` до отправки.

### backfill.py

- `run_backfill` переведён на **keyword-only** параметры; добавлены `seasons_last_n`, `tournament`, `store_path`, `bookmaker_key`.
- Вспомогательные функции: `_SeasonRow` (dataclass), `_parse_season_rows_from_book_root`, `last_n_season_windows`, `_backfill_date_range` (возвращает `(DataFrame, hit_quota: bool)`), `_concat_dedup`, `_read_quota_budget`, `_resolve_team_registry`, `default_odds_store_path`.
- Логика quota stop: при `QuotaBudgetError` в `_backfill_date_range` данные уже собранных дней сохраняются, функция возвращает `hit=True`; в `run_backfill` при `hit_quota=True` вызывается upsert и цикл по сезонам прерывается — прогресс не теряется.
- `TeamNameRegistry` подключён через `_resolve_team_registry` и передаётся в `backfill_day_frames → events_to_odds_frame`.
- CLI: `--from/--to` стали опциональными (но обязательны в паре при отсутствии `--seasons`), добавлены `--seasons N`, `--tournament`, `--store [PATH]` (без значения — default path).

### tests/test_odds_backfill.py

9 новых тестов:
- `test_last_n_season_windows_from_project_config` — читает реальный конфиг.
- `test_default_odds_store_path` — проверяет путь по умолчанию.
- `test_main_rejects_seasons_with_from_to` — CLI-валидация.
- `test_main_requires_range_or_seasons` — CLI-валидация.
- `test_main_passes_explicit_store_path_to_run_backfill` — store-path прокидывается.
- `test_run_backfill_seasons_and_store_upsert` — пустой API → upsert не вызывается.
- `test_run_backfill_range_with_store_non_empty_upserts` — non-empty → upsert вызывается.
- `test_backfill_stops_on_quota` — `_backfill_date_range` возвращает `hit=True`.
- `test_client_quota_raises_before_second_request` — `QuotaBudgetError` после лимита.
