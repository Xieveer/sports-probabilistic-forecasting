# R21.2 — Конфигурация: multi-bookmaker profiles + snapshot discovery

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-04-25
> **Приоритет:** 🔴 High
> **Сложность:** Low

---

## Задача

Добавить в конфигурацию The Odds API:
- `bookmaker_profiles` — per-bookmaker семантика (winner/winner_withOT, total/total_withOT, has_draw).
- `snapshot_discovery` — параметры динамического поиска open/close снимков (R21.4+).
- Deprecation-комментарии для `backfill.open_snapshot_utc` / `close_snapshot_utc` (оставить как fallback).
- В `conf/source/nhl.yaml`: добавить `bookmakers: [pinnacle, onexbet]`.

---

## Решение

### conf/bookmaker/the_odds_api.yaml

**Добавлена секция `bookmaker_profiles`:**
```yaml
bookmaker_profiles:
  pinnacle:
    key: pinnacle
    winner_semantics: winner_withOT
    total_semantics: total_withOT
    has_draw: false
  onexbet:
    key: onexbet
    winner_semantics: winner
    total_semantics: total
    has_draw: true
```
Контракт: `winner/total` = regulation (основное время); `winner_withOT/total_withOT` = полный матч (ОТ/буллиты).

**Добавлена секция `snapshot_discovery`:**
```yaml
snapshot_discovery:
  open_probe_offsets_hours: [168, 72, 24]   # 7d → 3d → 1d до матча
  close_margin_hours: 1                      # 1ч до commence_time
```
Параметры будут потребляться модулем `snapshot_discovery.py` (R21.4). Секция `backfill.open/close_snapshot_utc` сохранена с комментарием `# deprecated: fallback`.

**Сохранена секция `output_columns`** — legacy V1 имена для обратной совместимости R19/R20 (enrichment и merge в source.csv пока используют их до R21.3/R21.6).

### conf/source/nhl.yaml

Добавлена строка в секцию `odds`:
```yaml
bookmakers: [pinnacle, onexbet]
```
Все поля R20 (`enabled`, `bookmaker`, `sport_key`, `store_path`, `state_path`, `unmatched_report_path`, `min_odds_coverage_pct` и пр.) сохранены без изменений.

### tests/test_odds_config.py (новый файл)

5 тестов:
- `TestTheOddsApiBookmakerProfiles::test_profiles_keys_and_schema` — наличие профилей для `pinnacle`/`onexbet`, тип полей.
- `TestTheOddsApiBookmakerProfiles::test_pinnacle_onexbet_semantics_contract` — конкретные значения семантики и `has_draw`.
- `TestTheOddsApiSnapshotDiscovery::test_snapshot_discovery_types` — типы `open_probe_offsets_hours` (list[int]) и `close_margin_hours` (Real).
- `TestTheOddsApiSnapshotDiscovery::test_snapshot_discovery_non_empty_offsets` — список непустой (≥1 элемент).
- `TestNhlSourceOddsBookmakers::test_nhl_odds_includes_configured_bookmakers` — `bookmakers == ["pinnacle", "onexbet"]` и R20-поля (`enabled`, `bookmaker`, `sport_key`, `store_path`, `state_path`) на месте.

Все 5 тестов прошли. Суммарно `uv run pytest -k odds`: **99 passed**.
