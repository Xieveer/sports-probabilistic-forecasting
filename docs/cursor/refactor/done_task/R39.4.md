## Решение

Добавлен модуль `sports_forecast.orchestration.post_refresh_digest`: точка входа `python -m sports_forecast.orchestration.post_refresh_digest` читает предстоящие предсказания через `PredictionRepository.get_upcoming_predictions`, обогащает их `batch_live_response_extras`, собирает текст `build_post_refresh_digest_text` с provenance из `models/<tournament>/<market_spec>/best/deploy.yaml` (`format_provenance_from_deploy_dict`). Режим `--dry-run` печатает сообщение в stdout; иначе отправка одним `sendMessage` через новый `telegram_http.telegram_send_message` (urllib, без aiogram). Переменная `SF_TELEGRAM_DIGEST_ENABLE` в значениях `0`/`false`/`no` отключает прогон **без** `--dry-run` (код 0, без обращения к БД). В `digest_message` в `__all__` экспортирован `OddsWarning` для CLI. Документация — подраздел в `docs/source/nhl_local_operations.rst`. Тесты: `tests/test_post_refresh_digest_cli.py`.
