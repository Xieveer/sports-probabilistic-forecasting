# R21.3 — Enrichment: total line (point) + multi-bookmaker extraction

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-04-25
> **Приоритет:** 🔴 High
> **Сложность:** High

---

## Описание задачи

Расширить `enrichment.py` для поддержки:
1. Извлечения базы тотала (`point`) из `outcomes[].point` — помимо цен over/under.
2. Обобщённого извлечения по нескольким букмекерам из одного API-ответа.
3. V2 naming contract: `winner_withOT`/`total_withOT` для Pinnacle, `winner`/`total` для 1xBet.
4. Полной backward compatibility с R19/R20 вызовами.

---

## Решение

**`_totals_line_and_prices(bm) → (line, over_price, under_price)`**
— новая функция. Сначала читает `point` из поля `mkt["point"]`, затем fallback на первый outcome с непустым `point`. Возвращает тройку; старая `_totals_over_under` переведена в thin shim поверх неё (backward compat).

**`BookmakerExtractionProfile` (frozen dataclass)**
— профиль извлечения: `api_key`, `column_prefix`, `winner_semantics`, `total_semantics`, `has_draw`. Строится из `bookmaker_profiles.<name>` секции YAML или тестового dict через `from_mapping`. Конфиг R21.2 (Pinnacle: `winner_withOT/total_withOT`, 1xBet: `winner/total`) передаётся сюда напрямую.

**`extract_bookmaker_row_from_event(ev, profile, *, snapshot_role, team_registry)`**
— новая обобщённая функция. Генерирует словарь только из колонок этого букмекера по V2-контракту (`{prefix}_{winner_semantics}_{side}_{role}`). При отсутствии букмекера в событии — все `None`.

**`extract_pinnacle_row_from_event` → alias**
— сохранена публичная функция с прежней сигнатурой; делегирует в `_extract_row_legacy_pinnacle`. Никаких изменений для вызывающего кода R20.

**`events_to_odds_frame` — unified entry-point**
— принимает опциональные `book_cfg` и `bookmaker_profiles`. Если профили найдены — маршрутизирует в `_events_to_odds_frame_v2` (V2 multi-bookmaker path); иначе — в `_events_to_odds_frame_legacy` (R19/R20 path, `output_columns`-based, без изменения контракта).

**`_events_to_odds_frame_v2`**
— итерирует все профили из одного API-ответа, мёрджит в одну строку на event. `commence_time_utc` извлекается через `_parse_commence_time_utc` (ISO-8601 → UTC с обрезкой microseconds).

**`store._coerce_input_to_v2`**
— добавлен `_frame_has_v1_odds_columns` (проверка `pinnacle_home_open`), чтобы корректно детектировать V1-фреймы, которые теперь содержат `commence_time_utc` (добавленный legacy enrichment). V1 мигрирует через `migrate_v1_to_v2`; `commence_time_utc` при этом сохраняется.

**`backfill.backfill_day_frames`**
— добавлена передача `book_cfg=book_root` в оба вызова `events_to_odds_frame`. Включает multi-bookmaker extraction без изменения CLI-контракта.
