## Решение

Скрипт `scripts/run_nhl_refresh_notify.py` по умолчанию после refresh/validate вызывает `python -m sports_forecast.orchestration.post_refresh_digest` (те же аргументы турнира/рынка, `capture_output`, код возврата от digest; при сбое пайплайна — dry-run в stdout и `1`). Сохранён флаг **`--legacy-api-summary`** для HTTP `/predict/upcoming/nhl` и прежней сборки тела + Telegram. Обновлены help/Makefile (`nhl-morning-test-notify`), runbook `docs/source/nhl_local_operations.rst`. Добавлен unit-тест `tests/test_run_nhl_refresh_notify.py` на путь `--skip-telegram --skip-pipeline` (один вызов subprocess с `--dry-run`).
