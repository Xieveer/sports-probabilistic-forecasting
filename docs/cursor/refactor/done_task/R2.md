# R2. Ревизия контекстных колонок и multi-metric EWM

> **Статус:** ✅ Выполнено
> **Выполнено:** 2026-03-13
> **Приоритет:** 🟡 Medium
> **Сложность:** Medium

---

## Проблема

EWM генератор работал только с одной метрикой (`diff_ps`). Контексты были неполными: `tour_num` и `tour_match_num` не были доступны для table tennis, cyberhockey не имел контекста «консольная команда», именование H2H фичей было неконсистентным. Count генератор дублировал подсчёт для каждой метрики.

---

## Решение

1. **Multi-metric EWM:** Два экземпляра EWM генератора (`ewm_diff` по `diff_ps`,
   `ewm_total` по `total_ps`). `metric_label` определяет суффикс в именах.
   Naming convention: `{player}_{context}_{metric_label}_ewm_{span}`.

2. **tour_num из tour_datetime:** Новый трансформ `hour_to_time_of_day` в
   `clean.py` маппит час → время суток (0-night, 1-morning, 2-day, 3-evening).
   Применяется на sport-уровне для cyberhockey и table tennis.

3. **Team context для cyberhockey:** `home_team_name_en` / `away_team_name_en`
   прокинуты как `home_cteam` / `away_cteam` → `pl_cteam` / `opp_cteam` в long.
   Добавлен контекст `team` в EWM и Count генераторы (soft-fail для TT).

4. **H2H naming:** `h2h` → `h2h_global`, `output_suffix` → `metric_label`.
   Пример: `h2h_global_diff_ewm_5`, `h2h_global_total_ewm_5`.

5. **Count единожды:** Count генератор считает матчи один раз на контекст,
   независимо от метрики (diff/total).

6. **match_state как контекст:** `match_state`, `pl_state`, `opp_state` —
   контекстные колонки (без `f_` prefix), доступные для EWM/Count группировки.

7. **Новые контексты:** `form` (по `pl_state`), `weekday`, `team`, и
   соответствующие H2H-варианты.

## Изменённые файлы

- `sports_forecast/features/generators/ewm_generator.py` — multi-metric,
  `metric_label`, naming helpers, валидация
- `sports_forecast/features/generators/count_generator.py` — один count на контекст
- `sports_forecast/features/generators/form_generator.py` — `match_state` как
  контекстная колонка (не фича)
- `sports_forecast/data/clean.py` — трансформ `hour_to_time_of_day`
- `conf/features/generators/rolling/standard.yaml` — 2 EWM + 1 Count, полный
  набор контекстов
- `conf/features/generators/rolling/minimal.yaml` — 2 EWM + 1 Count, базовый набор
- `conf/features/_common.yaml` — `total_ps` в `result_cols`, `match_state`
  убран из `exclude_cols`
- `conf/sport/cyberhockey.yaml` — `derived_columns.tour_num`, `home_cteam`/
  `away_cteam` маппинг
- `conf/sport/table_tennis.yaml` — `derived_columns.tour_num`
- `conf/tournament/uel_*.yaml` (3 файла) — убран старый `tour_num` derivation,
  добавлены `home_cteam`/`away_cteam` в `select_columns`
- `conf/tournament/lp_*.yaml` (4 файла) — `tour_match_num`, `tour_num` в
  `select_columns`
- `tests/test_feature_generators.py` — обновлены все тесты: multi-metric naming,
  backward compat, soft-fail для отсутствующих колонок, warmup, pipeline integration
