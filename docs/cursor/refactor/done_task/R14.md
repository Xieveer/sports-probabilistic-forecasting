# R14. Source-адаптеры: подключение внешних поставщиков данных

> **Статус:** ✅ Выполнено
> **Приоритет:** 🔴 High
> **Сложность:** Medium
> **Выполнено:** 2026-04-04

---

## Проблема

Текущий ingest-слой (`sports_forecast/data/ingest.py`) жёстко завязан на чтение статических CSV-файлов из `data/source/<name>/source.csv`. Единственный способ добавить новые данные — положить файл вручную. У пользователя нет доступа к текущим фидам обновлений, и нет механизма для автоматического подтягивания данных через API, парсеры или другие внешние источники.

**Цель:** ввести паттерн адаптеров (`SourceProvider`), чтобы:
1. Сохранить совместимость с текущим файловым источником (CSV).
2. Позволить подключать новые провайдеры (HTTP API, scrapers, database) через конфигурацию.
3. Не менять downstream-контракт: ingest по-прежнему выдаёт `data/raw/<tournament>/matches.parquet`.

---

## Решение

Введён пакет `sports_forecast/data/providers/` с четырьмя модулями:

- **`base.py`** — ABC `SourceProvider` с методами `fetch(source_name) -> Path` и `is_available() -> bool`; иерархия исключений: `SourceProviderError` → `SourceDataNotFoundError` (+ `FileNotFoundError`), `SourceFetchError`.
- **`file_provider.py`** — `FileSourceProvider`: оборачивает прежнюю схему `data/source/<name>/source.csv` один-к-одному, не меняя логику чтения в `ingest.py`.
- **`http_provider.py`** — `HttpApiSourceProvider` (PoC): выполняет `GET`-запрос к URL из конфига, сохраняет ответ как `source.csv`, поддерживает таймауты и `urllib3.Retry` с `backoff_factor`.
- **`registry.py`** — `ProviderRegistry` и фабричная функция `get_provider(source_cfg, paths_cfg) -> SourceProvider`; при отсутствии поля `provider.type` дефолт — `file`. Неизвестный тип → `UnknownProviderTypeError`.

`ingest.process_tournament()` адаптирован: загружает source-конфиг (если есть), создаёт провайдер через `get_provider()` и вызывает `fetch()`; при `SourceDataNotFoundError` — `warning`/skip, при прочих `SourceProviderError` — `error`/skip. Существующий downstream-контракт (Parquet) не затронут.

Три существующих source-конфига расширены полем `provider.type: file`. Документация `HOW_TO_ADD_NEW_TOURNAMENT.md` дополнена шагом 2а и секцией «Как создать свой SourceProvider».
