## Решение

Материализация для **winner** с лучшей парой algorithm/features по R12.6: **logreg** + **advanced**.

Команды:

- `make materialize TOURNAMENT=uel_kz_1 MARKET=winner SPEC=winner ALG=logreg FEAT=advanced`
- `make materialize TOURNAMENT=lp_ru MARKET=winner SPEC=winner ALG=logreg FEAT=advanced`

Первая попытка падала на SQLite: в старой `predictions.db` не было колонки `model_tag`. Добавлена лёгкая миграция в `sports_forecast/service/db/engine.py`: `_ensure_sqlite_predictions_schema` вызывается из `init_db` после `create_all`.

Итог: записи в Prediction Store и parquet `data/predictions/{tournament}/winner/predictions_prod.parquet`.
