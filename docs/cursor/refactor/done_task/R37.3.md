# R37.3. Порог edge и типизированное решение bet / no_bet / insufficient_data

> **Сложность:** Low

## Решение

Добавлен модуль `sports_forecast/betting/edge_decision.py`: enum `BetDecision`, `EdgeDecisionParams`, функции `implied_probability_from_decimal`, `compute_edge`, `decide_bet` (сравнение `p_model` с `1/decimal_odds`, парсинг `odds_raw` не дублируется — на вход подаётся уже decimal). Пороги читаются из `conf/service_api.yaml` (`edge_threshold`, `min_odds`) через `sports_forecast.service.service_api_settings.load_edge_decision_params` с опциональным override env (`SERVICE_API_EDGE_THRESHOLD`, `SERVICE_API_MIN_ODDS`) и кешем; сброс кеша для тестов — `reset_service_api_settings_cache`. В `conf/betting.yaml` добавлен комментарий о согласованности формулы implied с `service_api`. Юнит-тесты: выше порога, на границе (инклюзивный `>=`), ниже, недостаточные данные (odds/proba), согласованность `compute_edge` с implied. Роутер не изменялся (жёсткого порога там нет; интеграция — R37.5).
