## Проблема

Текущий набор фичей (195 `f_`-колонок) покрывает базовые EWM по `diff_ps`/`total_ps`,
форму, расписание, таблицу, ростер и время. Однако:

1. **EWM считается по `pl_points` (= `home_score_ft`)**, что не совпадает с таргетом
   `winner_withOT` (`pl_goals_full > opp_goals_full`). Для OT-рынков метрики EWM
   должны строиться по `goals_full`, не по `points`.
2. **Нет EWM по игровой статистике** (SOG, blocks, hits, penalties, faceoffs) —
   хоккейно-специфичные сигналы.
3. **Нет streak-фичей** (серия побед/поражений) — простой momentum-индикатор.
4. Отсутствует span=15 (средний горизонт между 5 и 25).
5. Нет внутрисезонного EWM-контекста (сброс в начале каждого сезона).
6. Roster quality можно усилить (рост нападающих, возраст защитников, смена вратаря).
7. Мотивация / плей-офф-гонка покрыта минимально; нет bubble-indicator.
8. Schedule-фичи в `home/away` формате, а не `pl/opp`.

Цель: ~280–350 фичей после Feature Engineering v2, с правильным маппингом метрик
на рынок, сокращёнными spans [5, 15] + inseason, и lineup-сигналами без OHE.

### Phase 5: Lineup features (без OHE)

- [ ] **R27.9** Lineup encoding features — состав как агрегированные сигналы
  - Добавить в `NhlRosterFeatureGenerator` (или вынести в отдельный `LineupFeatureGenerator`):

  **a) Lineup continuity** (Jaccard с предыдущим матчем):
    - `lineup_continuity` = |current ∩ prev| / |current ∪ prev| по player_id
    - Proxy: изменился ли состав (травмы, trade deadline, ротация)
    - Реализация: groupby `[home_team]` sort by datetime, сравнить frozenset(sweater numbers) current vs prev row

  **b) Player seniority aggregation** (опыт конкретного состава):
    - `roster_mean_seniority` = среднее cumulative appearances до матча для игроков состава
    - `roster_min_seniority` = минимальное (слабое звено / дебютанты)
    - cumulative appearances = cumcount by sweater number + team (pre-computed, shift=1)
    - Отражает: "насколько опытен конкретный состав сегодня"

  **c) Roster stability index** (последние N матчей):
    - `roster_stability_5` = mean(lineup_continuity) по последним 5 играм
    - Отражает: хронически нестабильная vs стабильная команда

  - Все фичи генерируются для home и away, затем конвертируются в pl/opp через side
  - Конфиг: `conf/features/generators/roster/nhl.yaml` (параметры: stability_window, seniority_smoothing)
  - **Файлы:** `sports_forecast/features/generators/roster_generator.py`,
    `conf/features/generators/roster/nhl.yaml`

## Риски и митигации

| Риск | Вероятность | Митигация |
|------|------------|-----------|
| Hydra merge нескольких rolling profiles конфликтует по ключам | Medium | Уникальные ключи генераторов в каждом YAML (ewm_diff vs ewm_goals_full_diff) |
| Слишком много фичей → overfitting | Medium | Feature selection (R18) + regularisation; мониторинг через Optuna |
| `season` отсутствует в long format | Low | Проверить wide_to_long; `season` — meta-колонка, проходит автоматически |
| Stats columns NaN для старых сезонов | Medium | min_periods в EWM обрабатывает; warmup не нужен |
| goalie_change требует stateful shift по team | Low | groupby + shift, аналогично streak |
