# R23. CI/CD, секреты и production deploy на VPS

> **Статус:** 🟡 В работе
> **Приоритет:** 🔴 High
> **Сложность:** High

---

## Проблема

Нет автоматической проверки PR, нет сборки и публикации образов, нет воспроизводимого production-compose с TLS, лимитами и мониторингом. Секреты не задокументированы шаблоном. Это **отдельный трек** от обучения NHL (**R22**) и от UX бота (**R24**), чтобы не раздувать один эпик.

**Граница эпика:** GitHub Actions (или аналог), `.env.example`, deploy hook, `docker-compose.prod`, reverse proxy, Prometheus/Grafana для prod, расписание обновления данных. Код бота не входит (см. **R24**).

---

## Связь с другими эпиками

- Можно выполнять **параллельно с R22** (R23.1–R23.4 не требуют обученной модели).
- **R23.5–R23.8** удобнее после появления образа из CI; для полного e2e — после **R22.3** (есть что materialize), но compose и TLS настраиваются и на заглушке.

---

## Что сделать

### CI/CD и секреты

- [ ] **R23.1** GitHub Actions: lint + test on PR — `.github/workflows/ci.yml`: `uv sync`, `make lint`, `make test-unit`, Python 3.10+, кеш uv.
- [ ] **R23.2** GitHub Actions: Docker build + push — `.github/workflows/docker.yml`: multi-stage (api, bot, …), push в `ghcr.io` на merge в `main`, теги `sha` + `latest`.
- [ ] **R23.3** `.env.example` + управление секретами: переменные для Postgres, бота, Odds API, MLflow, Grafana; документ GitHub Secrets vs `.env` на сервере; `.gitignore` для `.env` при необходимости.
- [ ] **R23.4** GitHub Actions: deploy hook (опционально) — `.github/workflows/deploy.yml`: SSH + `docker compose pull && up -d`; триггер `workflow_dispatch` ± push; secrets `DEPLOY_HOST`, `DEPLOY_SSH_KEY`; зависимость от успешного CI.

### Production runtime

- [ ] **R23.5** Сервер и `docker-compose.prod.yml`: требования (например 4 vCPU / 8 GB для train на том же хосте; 2 vCPU / 4 GB для inference-only); override: limits, restart, log rotation, env prod.
- [ ] **R23.6** Reverse proxy + HTTPS: Caddy или nginx в compose, Let's Encrypt, прокси на API; опционально Grafana/MLflow за basic auth.
- [ ] **R23.7** Observability production: scrape `/metrics`, дашборды Grafana, алерты (latency, freshness прогнозов, диск).
- [ ] **R23.8** Scheduled data refresh: cron / systemd timer / Airflow — периодический NHL refresh, idempotency и lock как в архитектуре проекта.

## Риски и митигации

| Риск | Митигация |
|------|-----------|
| Утечка секретов в логах CI | только GitHub Secrets, не echo |
| Деплой ломает сервис | manual `workflow_dispatch`, healthchecks, `restart: unless-stopped` |
