# R16. MLflow: сравнительная визуализация метрик по запускам

> **Статус:** 🟡 В работе
> **Приоритет:** 🟡 Medium
> **Сложность:** Medium

---

## Проблема

При проведении sweep-обучения (например, ~50 запусков на один турнир+рынок с комбинациями catboost/lgbm/logreg/dummy/stacking × basic/advanced × разные seed/feature selection) результаты логируются в MLflow, но нет удобного способа:
1. Сравнить все запуски на одном экране (графики X=run index, Y=metric, линии по алгоритмам).
2. Фильтровать запуски по турниру, рынку, алгоритму, набору фичей.
3. Видеть динамику метрик по итерациям feature selection.

MLflow UI даёт таблицу и scatter-plot, но не даёт осмысленного «timeline» сравнения. Для принятия решений о promote нужна более наглядная картинка.

**Цель:** стандартизировать логирование для сравнения и создать инструмент визуализации (скрипт/notebook), который по одному эксперименту строит comparative chart.

**Допущения:**
- Текущие теги (`tournament`, `algorithm`, `featureset`, `market_spec`, `seed`) уже логируются — они достаточны для группировки.
- Не нужен отдельный production-дашборд; достаточно скрипта, который можно запустить локально.
- Grafana-экспорт — опциональное расширение (Low priority), не блокирует основной deliverable.
- Порядковый индекс (`run_index`) можно вычислить из `start_time` MLflow run (сортировка по времени старта).

Сохраняет PNG + показывает в окне. Использовать `mlflow.search_runs()` API.
- [ ] **R16.4** Добавить Makefile-цель `make compare` с параметрами `EXP`, `METRIC`, `GROUP` (вызывает `scripts/mlflow_compare.py`).
