# Architecture Decision Records

В этом каталоге хранятся значимые и труднообратимые архитектурные решения. Новый ADR создаётся
из [шаблона](0000-template.md), имеет статус `proposed` до согласования и ссылается на
подтверждённое требование.

Локальные решения, не меняющие границы, внешний контракт, зависимость, хранилище или модель
развёртывания, ADR не требуют.
