# ADR-001 — Единственный runtime Python 3.12

> **Статус:** accepted
> **Дата:** 2026-08-07
> **Связанное требование:** [REQ-001](../../product/requirements/REQ-001-python-312.md)

## Контекст и критерии выбора

Локальная среда использует Python 3.10, основной Dockerfile и Airflow образ также закреплены
на 3.10, а CI проверяет одновременно 3.10 и 3.12. Скрипт AI-валидации использует стандартный
модуль `tomllib`, который доступен с Python 3.11, поэтому в текущем окружении Python 3.10
не запускается. Нужна одна поддерживаемая версия для локальной разработки, CI и runtime.

## Рассмотренные варианты

1. **Status quo:** поддерживать 3.10 и 3.12. Не устраняет несовместимость `tomllib`, увеличивает
   матрицу CI и сохраняет разный runtime.
2. **Python 3.12:** поддерживаемая в Airflow 2.10.4 версия, доступен образ
   `apache/airflow:2.10.4-python3.12`; едина для CI, сервисов и локальной среды.
3. **Python 3.13+:** требует отдельной проверки всего ML/Airflow стека и выходит за требование.

## Решение

Поддерживать только Python 3.12: `requires-python = ">=3.12,<3.13"`, `.python-version`,
единственная версия CI и образы `python:3.12-slim` / `apache/airflow:2.10.4-python3.12`.

## Последствия

- Положительные: единый runtime, доступен `tomllib`, сокращается CI-матрица.
- Отрицательные и стоимость: локальные Python 3.10 окружения нужно пересоздать; старые
  потребители пакета на Python 3.10/3.11 больше не поддерживаются.
- Безопасность и эксплуатация: deployment не выполняется этой задачей; перед rollout требуется
  сборка образов и стандартный healthcheck.

## Проверка и пересмотр

Проверить `uv lock --check`, `uv sync --frozen --python 3.12`, unit-тесты и Docker build.
Пересмотреть ADR, если ключевая зависимость не разрешается или не работает на Python 3.12;
откат — вернуть предыдущий runtime-контракт и lockfile отдельным согласованным изменением.

## Источники и неизвестное

- [Airflow 2.10.4 release notes](https://airflow.apache.org/docs/apache-airflow/2.10.4/release_notes.html)
  фиксируют официальную поддержку Python 3.12.
- [Тег Airflow 2.10.4-python3.12](https://hub.docker.com/layers/apache/airflow/2.10.4-python3.12/images/sha256-94b74c8b65924179b961b8838e9eaff2406d72085c612e0f29b72f886df0677e)
  существует в Docker Hub.
